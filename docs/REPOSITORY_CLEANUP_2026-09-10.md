## 현재 기준과 로컬 부산물 정리

- README·AI_START_HERE·PROJECT_STATUS에서 오래된 완료 주장과 낡은 단일 기준을 정리하고, 사용자 지시·정책·디자인·실행 증거의 적용 범위를 명시했다.
- 앱·관리자, 디자인 ZIP, 인프라 검수 보고서와 재현 자료를 저장소 내부의 유효한 경로로 연결했다. 결과는 검수 시점의 스냅샷이며 제품 결함 해결이 아니다.
- 최신 ZIP의 경로·해시·충돌은 [접수 기록](design-handoff/INTAKE-2026-09-10.md)에 남겼다. 47 MB 원본 ZIP·420개 추출 파일을 중복 추가하거나 `current/`를 통째로 덮어쓰지 않았다.
- `.gitignore`·`.dockerignore`에 검수 임시 파일·격리 체크아웃·로컬 자격증명 전달 폴더를 제외했다. 해당 로컬 폴더나 자격증명 내용은 삭제·복사하지 않았다.
- `weddingpick.kr`은 **보유한 커스텀 도메인·현재 미사용**으로 통일했다. CI의 자동 도메인 연결 단계와 선언된 활성 CORS 출처에서 제거했다. 도메인 자체와 실제 DNS는 변경하지 않았다. `infra/render-env.yml` 변경은 main 병합 후 기존 env-sync의 운영 반영 대상이므로 결과를 따로 확인한다.

## 검사 중 발견한 Windows 호환성

기존 배지 검사에서 셸 문자열의 작은따옴표 때문에 Windows의 `git ls-files` 결과가 비어 2개 테스트가 실패했다. `execFileSync` 인자 배열로 바꿔 모든 운영체제에서 동일한 파일을 검사하게 했다. 기존 SVG 비교 1개는 Git의 CRLF 변환만 실패 원인이어서 비교 시 CRLF를 LF로 정규화했다. 검사할 내용·문구·디자인 기준은 유지했다.

검사 결과와 독립 검토는 [정리 상태](sync/repository-cleanup-status.json)에 기록한다. DB 통합 테스트는 운영 DB 연결 없이 건너뛰며 통과로 계산하지 않는다. UI 변경이 없어 이번 정리에 대한 화면 캡처 검수는 적용하지 않는다. 기존 앱·관리자 UI 결함과 전체 시각 검수 미완료는 [현재 상태](../PROJECT_STATUS.md)에 남아 있다.
