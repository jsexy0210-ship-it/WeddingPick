# 최신 사용자 디자인 ZIP 접수 기록

사용자가 2026-09-10 전달한 `웨딩픽_프로젝트.zip`을 최신 전달 자료로 접수했다. 파일 이름이나 버전 번호만으로 기존 `current/`와 같은 내용이라고 판단하지 않는다.

| 항목 | 확인값 |
|---|---|
| 원본 위치 | 사용자 제공 `C:/Users/PC/Desktop/웨딩픽_프로젝트.zip` |
| 크기 | 47,399,020 bytes |
| SHA-256 | `B972F948592B757EE994062C11CBCE58153CCDA31742F24FF4D63D748078AEA3` |
| 대조한 Git | `e34193ee1644c664f107d529002ae53ef775389a` |
| 구성 | 파일 420개, HTML 89개, 루트 화면 문서 36개, 복수 과거 handoff 폴더 |
| 대조 | 루트 화면 HTML 36개 중 정규화 비교 17개 동일·19개 상이. 상이를 모두 신규 사양으로 해석하지 않음 |

원본 ZIP은 사용자 파일로 보존한다. 47 MB 원본과 추출 디렉터리를 중복 커밋하지 않고 [대조 결과](../DESIGN_ZIP_AUDIT_2026-09-10.md), [파일 매핑](../design-zip-audit-2026-09-10.json), [이미지 검사](../design-zip-images-2026-09-10.json)를 공유한다. 검수 기록은 원본 디자인 파일을 대체하지 않는다.

## 적용 경계

`current/`는 현재 Git에 반영된 v3.27 기준본이다. 새 ZIP과 완전히 일치하거나 ZIP 검수가 끝난 상태가 아니다. 사용자 확정 사항은 우선 적용하되, 아래 충돌은 화면 ID·기준 HTML·동일 상태 캡처를 연결해 해소한 뒤 파일별로 반영한다. 여러 세대의 폴더를 통째로 덮어쓰지 않는다.

| 항목 | 충돌·확인 사항 |
|---|---|
| 검색 | 루트 HTML의 결과 직접 진입과 SPEC의 검색 홈 구조가 다름 |
| 제보 | 삭제된 WP-RPT-004/005/006/010이 screens와 과거 handoff에 활성으로 남음. 직접 입력 설명도 충돌 |
| 나이 | 콘솔·최신 구현은 `age_range`. ZIP 일부 출생연도 설명으로 되돌리지 않음 |
| 날짜 | 달력과 폐기된 휠 설명이 ZIP 안에 공존 |
| D-day | 코랄·회색 규칙 충돌. Git의 사용자 확정 기록도 대조 필요 |
| 관리자 | 기본 HTML은 Git과 동일하지만 1,440×900·사이드바 216px. 운영 HTML·ADMIN.md는 1,920×1,080·240px라 원본 간 충돌이 남음 |
| 기준 이미지 | `.png` 26개가 실제 JPEG이고 문서 일부만 잘려 있음. 전체 화면 비교 증거로 사용 불가 |

CHANGELOG는 최신 항목부터 읽는다. 다만 새 전달본 자체의 모순을 버전 번호로 덮지 않는다. 화면·기능 검수 완료 여부는 [현재 상태](../../PROJECT_STATUS.md)와 별도로 기록한다.
