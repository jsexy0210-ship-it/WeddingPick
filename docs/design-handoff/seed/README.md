# Handoff: 웨딩픽 (WeddingPick)

결혼 준비 커플을 위한 모바일 앱 · 웹 · 운영 관리자 전체 디자인 패키지입니다.

---

## Overview

**웨딩픽은 웨딩업체를 찾아다니는 앱이 아니라, 웨딩픽이 먼저 골라주고 사용자는 비교해서 Pick하는 앱입니다.**

핵심 루프는 `상황 → 추천 → 근거 → Pick`입니다. 사용자가 정보를 직접 분석하게 만들지 않습니다.

서비스의 연료는 **확인된 정보**입니다. 사용자가 실제로 낸 금액을 자료로 인증(Pick 인증)하면 업체별 금액 구간이 만들어지고, 그 정보로 다음 사용자가 판단합니다. 광고를 받지만 광고비는 추천 순위에 영향을 주지 않습니다.

Root Navigation은 5개입니다. **홈 | 검색 | Pick | 우리웨딩 | MY**

- **홈** — 웨딩픽이 지금 필요한 것을 먼저 제안
- **검색** — 사용자가 직접 찾음 (추천 문구를 넣지 않는 유일한 탭)
- **Pick** — 후보를 모으고 비교해서 최종 결정
- **우리웨딩** — 결정한 뒤 일정 · 지출 · 준비 관리
- **MY** — 계정 · 제보 · 혜택 · 설정

## About the Design Files

이 폴더의 `.dc.html` 파일은 **HTML로 만든 디자인 레퍼런스**입니다. 그대로 복사해 쓰는 프로덕션 코드가 아닙니다.

각 파일은 브라우저에서 바로 열립니다. 한 파일에 여러 화면이 나란히 배치되어 있고, 각 화면 위에 화면 ID(`WP-HOME-001` 등)와 설명이 붙어 있습니다.

**해야 할 일은 이 HTML 디자인을 대상 코드베이스의 환경으로 다시 구현하는 것입니다.** React Native · Flutter · SwiftUI · Kotlin 등 이미 정해진 환경이 있으면 그 환경의 기존 패턴과 컴포넌트로 만듭니다. 아직 환경이 없다면 프로젝트에 맞는 것을 선택합니다.

파일 구조에 관한 참고사항:
- `support.js`는 디자인 파일을 브라우저에서 렌더링하기 위한 런타임입니다. 구현에는 필요하지 않습니다.
- `image-slot.js`는 이미지 자리 표시자입니다. 실제 앱에서는 일반 이미지 컴포넌트로 대체합니다.
- 인라인 스타일로 작성되어 있습니다. 실제 구현에서는 코드베이스의 스타일 시스템을 사용하세요.

## Fidelity

**High-fidelity (hifi)** 입니다.

색상 · 타이포그래피 · 간격 · 컨트롤 높이 · 라운드 값이 모두 확정값입니다. 아래 Design Tokens 섹션의 값을 그대로 사용하세요.

두 가지 예외:
- **이미지** — 실제 사진이 아직 없어 샘플 5장을 돌려쓰고 있습니다. 규격만 맞추면 됩니다(Assets 섹션 참조).
- **폰트** — 시스템 서체를 사용합니다. 별도 웹폰트를 넣지 않습니다.

### Pick 인터랙션 (대표 인터랙션)

Pick 버튼은 웨딩픽에서 가장 중요한 행동입니다.

- 버튼이 아웃라인 → 코랄 채움으로 전환, 라벨 `Pick하기` → `Pick했어요`

### 광고 독립성 (구현 시 필수)

광고비와 요금제 등급은 다음에 영향을 주지 않습니다.

- 웨딩픽 TOP3
- 오늘의 Pick
- 개인화 추천
- 자연 검색순위
- 확인된 정보
- 후기 및 후기 순위

**광고 랭킹은 자연 추천과 분리된 별도 테이블로 관리합니다.** 광고 노출 시 `광고` 라벨을 반드시 표시합니다.

요금제 3단계 — LIGHT 30,000원(업체 상세) / STANDARD 70,000원(상세 + 검색) / PREMIUM 150,000원(상세 + 검색 + 지역 카테고리). 첫 달 무료 또는 50% 할인 1회, 영구 무료 없음.

### 회원탈퇴 시 데이터 처리

| 데이터 | 처리 |
|---|---|
| 계정 · 프로필 | 즉시 삭제 또는 법적 보관분 분리 |
| 배우자 연결 | 즉시 해제 |
| Pick · 취향 · 개인화 | 즉시 삭제 |
| 일정 · 체크리스트 · 지출 | 즉시 삭제 |
| 인증 자료 원본 | 검증 목적 달성 후 삭제 |
| 확인된 정보 (비식별) | 식별정보 제거 후 유지 |
| 작성 후기 | 작성자 식별정보 제거 후 유지 |
| 신고 · 분쟁 기록 | 처리 및 법적 필요기간 별도 보관 |
| 법령상 보존 항목 | 법정기간 후 삭제 |

**`탈퇴 = 개인정보 삭제`이고, 검증된 비식별 정보까지 삭제하는 것은 아닙니다.** 통합 보존기간(예: 30일)을 임의로 두지 않습니다. 항목별 법정기간은 개인정보처리방침 확정 단계에서 정합니다.

화면 문구는 세 곳이 완전히 같은 기준을 말해야 합니다 — 회원탈퇴 화면(WP-MY-008) · 이용약관 제12조 · 개인정보처리방침 보유기간 표.

- 안내 제목은 `탈퇴하면 계정과 개인화 정보는 삭제돼요`
- 보존 항목 그룹명은 `작성자 정보와 분리되는 정보` (「남는 것」이라고 쓰지 않음)
- 각 항목에 `익명` 배지 + `나를 알아볼 수 없도록 분리해 유지될 수 있어요`
- 특정 일수를 쓰지 않음
