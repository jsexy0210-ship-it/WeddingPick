## 용어
- 사용자 화면에 `AI` 금지. `웨딩픽이 골랐어요` · `웨딩픽 TOP3` · `웨딩픽 콘텐츠`. 내부 개발·관리자·비용관리 문서에서는 AI 용어 유지.
- 사용자 화면에 `데이터` 금지. `확인된 제보` · `확인된 제보 N건` · `많이 확인된 곳` · `아직 정보가 적어요`.
- 정보 체계 3단. 상위 개념 `확인된 제보` · 금액 `제보 금액` · 제공 행동 `Pick 인증`.
  `확인된 정보` `확인된 금액` `실제로 낸 금액` `실제 결제` `실제 결제 데이터`는 쓰지 않는다.
- 애매모호 표현 금지: `거의` `아마` `대략` `어느 정도` `가능성이 높음` `~일 것으로 보임` 근거 없는 `약`·`정도`.
  대신 `확정` `미확정` `검증 전` `확인 필요` `조건부` `측정값` `추정값`.
- `탐색` 금지 → `검색`. `관심업체` 폐기 → `Pick`.

## 디자인
- SEED Design System(Karrot) 기반. 좌우 Gutter 24px.
- 스킨 6종: Coral #FF6F61(기본) · Red #FF4D4D · Yellow #FFC041 · Green #34C759 · Blue #3182F6 · Dark Gray #191F28.
- 폰트는 시스템 서체 유지(Pretendard 미적용).
- 섹션 제목 1줄, 서브카피 사용하지 않음. 안내 최대 2줄, CTA 1줄.
- 화면당 Primary CTA 1개. Pick이 가장 중요한 행동, 비교는 보조.

## 예시 데이터
- 웹은 가명 업체(`강남 A 스튜디오` 형식)와 샘플 이미지를 유지한다. 실제 상호와 실제 촬영물을 노출하지 않는다.
- 앱은 실제 업체명과 실제 이미지를 쓴다. 시안의 가명은 개발 시 실제 데이터로 대체한다.
- 금액은 웹·앱 모두 확인된 제보로 집계한 실제 구간을 쓴다.

## 진행 상태
- 홈은 C-1 확정. `웨딩픽 홈 5안 비교` 파일은 참고용으로 보존.
- 광고 실운영 전환은 사용자 오더 대기.
- 실제 이미지 대기 중. 규격은 컴포넌트 시트 참조.
