## 1:1 싱크 기준

**화면 크기** — 390 × 844 (iPhone 14 Pro 논리 픽셀)

```
statusBar   44   ← 실기기는 useSafeAreaInsets().top
header      56
scroll      flex:1
dock        92   ← 있을 때만. + safe bottom
tabBar      72   ← Root 5탭만. + safe bottom
```

**좌우 Gutter 24px 고정.** 전 화면 예외 없음.

**리스트 행 최소 높이 56px.** 메타 텍스트가 있으면 padding 14, 없으면 12.

**CTA 높이** — Primary 52 / Secondary 48 / 카드 내 44.

같은 행 카드는 이미지 비율 · 텍스트 블록 높이 · CTA 하단선이 반드시 일치해야 합니다. `screens.json`의 `component.twoColCard`를 봅니다.

## HTML 원본 열기

`html/` 안의 `.dc.html`은 브라우저에서 바로 열립니다. 한 파일에 여러 화면이 나란히 있고 각 화면 위에 ID와 설명이 붙어 있습니다.

`support.js`는 렌더링 런타임입니다. 구현에는 필요하지 않습니다.
`image-slot.js`는 이미지 자리 표시자입니다. 실제 앱에서는 일반 이미지 컴포넌트로 대체합니다.

인라인 스타일로 작성되어 있습니다. 실제 구현에서는 코드베이스의 스타일 시스템을 씁니다.

## 절대 바꾸지 말 것

**Pick Mark** — `tokens.json`의 `symbol.paths` 두 개. 하트 안에 체크입니다. 다시 그리지 않습니다.

**용어 3단** — 확인된 제보(상위) / 제보 금액(금액) / Pick 인증(행동). 서로 대체할 수 없습니다.

**로그인 필수** — 비회원 이용이 없습니다. 스플래시 다음이 바로 로그인이고, 소셜 4종(카카오 · 네이버 · 구글 · 애플)만 지원합니다. 이메일 로그인 화면을 만들지 않습니다.

**하단 안전 여백** — 화면을 기기별로 두 벌 그리지 않습니다. 탭바 · dock · 시트에만 `+ max(safeBottom, 0)`을 더합니다. Android 3버튼은 inset이 0으로 오므로 별도 처리가 필요합니다. `tokens.json`의 `safeArea`와 `platform`을 봅니다.

**정보 4단계** — 확인된 제보 건수에 따라 금액 표기가 달라집니다. `SPEC.md` 2장.

**광고 독립성** — 광고 랭킹은 자연 추천과 분리된 별도 테이블. `SPEC.md` 7장.
