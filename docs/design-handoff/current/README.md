# 웨딩픽 · v3.21 로더 아이콘 세트 확장

로더 아이콘을 온보딩 12업종과 1:1로 맞췄습니다.

## 폴더

```
README.md · CHANGELOG.md · screens.json · SPEC.md · tokens.json   문서 5개 (덮어쓰기)
html/30-loading.dc.html                                           시안
```

## 바뀐 것

### 1 · 아이콘 5개 → 12개

```
결정사 · 웨딩홀
스튜디오 · 드레스 · 메이크업 · 헤어변형
본식스냅 · 부케 · 청첩장
예물 · 혼수 · 허니문
```

온보딩 진행 상황(3/5) 선택지와 같은 목록입니다. 신규 아이콘 4개 — 헤어변형 · 부케 · 청첩장 · 혼수.

**온보딩에 없는 업종을 로더에 넣지 않습니다.**

### 2 · 결정한 업종은 순회에서 제외

온보딩에서 결정 완료로 고른 업종은 로더가 돌지 않습니다.

```
전체 12업종 − 온보딩 결정 완료 업종 = 순회 대상
```

「지금 찾고 있는 것」만 보여줍니다. 이미 정한 웨딩홀을 다시 찾는 척하지 않습니다.

### 3 · 제목에 닉네임

```
변경 전   두 분에게 맞는 곳을 찾고 있어요
변경 후   {닉네임}님에게 맞는 곳을 찾고 있어요
```

「두 분」은 배우자 연결 여부와 무관하게 쓰이던 문구라 뺐습니다.

### 4 · 속도

```
작은 로더 (20 · 28)   아이콘당 820ms
전체 화면 로더 (40)    아이콘당 620ms
```

### 5 · 잔상 수정

아이콘이 바뀔 때 2~3개가 동시에 보이던 문제를 고쳤습니다. 키프레임이 5개 기준(20% 슬롯)으로 고정돼 있어 아이콘이 10개로 늘자 페이드가 슬롯을 넘었습니다.

```
@keyframes wpSwap10 { 0%,7%{opacity:1} 10%,100%{opacity:0} }
                           ↑ 홀드        ↑ 슬롯 끝에서 끊김
```

개수별 키프레임 8종(`wpSwap5`~`wpSwap12`)을 두고 `wpSwap${N}`으로 씁니다.

**하나의 키프레임을 모든 개수에 재사용하지 마세요.** 슬롯 = `100/N %`, 홀드는 슬롯의 70%까지, 페이드는 슬롯 끝에서 정확히 끝냅니다.
