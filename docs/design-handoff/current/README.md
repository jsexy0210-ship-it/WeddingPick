## Codex 전달 프롬프트

> `handoff-v3.27/`을 받았다. `ADMIN.md` · `CHANGELOG.md`는 덮어쓰기다.
>
> 관리자 운영 11화면을 구현한다. 라우트는 위 표 그대로. 캔버스는 1920×1080이고 사이드바 240 + 본문이다. 기존 관리자 화면도 1920 기준으로 맞춘다.
>
> **공통 규칙 4가지를 모든 화면에 적용한다.** ① 상단 배너가 상태를 먼저 말한다 — 정상 초록 / 확인 필요 주황 / 조치 필요 빨강. ② 빈 상태를 반드시 그린다, 「확인할 것이 없어요」가 정상이다. ③ 표는 카드 안에서만 가로 스크롤한다, 화면 전체를 흔들지 마라. ④ 긴급 중지와 변경 복구는 확인 카드를 띄우고 무엇이 바뀌는지 항목으로 보여준 뒤 진행한다.
>
> 숫자는 전부 `font-variant-numeric: tabular-nums`. 감사 기록의 event_id · source · reason_code는 모노스페이스.
>
> **권리 미확인 이미지는 승인 버튼 자체를 렌더링하지 마라.** 폐기와 출처 보강만 가능하다. 이메일 매칭은 확신도 0.85 미만이면 자동 연결하지 않는다. 마케팅 캠페인은 클릭률 2% 미만이 3일 연속이면 자동 정지하고 브리핑에 올린다.
>
> 내부 화면이므로 사용자 화면 용어 규칙(AI · 데이터 금지)을 적용하지 않는다. AI · 데이터 · 검증 · 반려를 그대로 쓴다.
