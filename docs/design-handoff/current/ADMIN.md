## 원칙

관리자는 데이터를 일일이 처리하지 않고 **AI 운영을 감독**합니다. 문제 없는 날에는 개별 큐를 열 필요가 없는 것이 목표입니다.

내부 화면이므로 사용자 화면 용어 규칙(AI · 데이터 금지)을 적용하지 않습니다. `AI`, `데이터`, `검증`, `반려` 같은 운영 용어를 그대로 씁니다.

**로그인 지속** — 신뢰기기 + 장기 보안 세션. IP는 보조 신호일 뿐이고, IP가 바뀌어도 신뢰기기면 로그아웃하지 않습니다. 비밀번호를 로컬에 평문 저장하지 않습니다. 재인증 조건은 4가지 — 직접 로그아웃 / 비밀번호·권한 변경 / 신뢰기기 해제 / 비정상 접근 탐지.

## 광고 실운영 전환 게이트 · WP-ADM-034

```
테스트 전체 오픈 → 판단 데이터 충족 → GPT 독립 분석
→ Claude 독립 분석 → 보고서 2건 → 사용자 최종 결정 → 실운영
```

종료일을 고정하지 않고 **판단 데이터 충족 여부**로 분석 시점을 정합니다. 두 AI의 판단이 갈려도 합의하지 않고 그대로 제출합니다. **오픈 스위치는 사람만 조작합니다.**

현재 상태 — 테스트 중 · 판단 데이터 미달 · 사용자 오더 대기

## 광고 독립성 · WP-ADM-033

광고 랭킹은 자연 추천과 **분리된 별도 테이블**로 관리합니다. 추천 쿼리에 광고 가중치 컬럼이 들어가면 안 됩니다.

영향을 주지 않는 항목 — 웨딩픽 TOP3 · 웨딩픽 추천 · 개인화 추천 · 자연 검색순위 · 실 제보 · 후기 및 후기 순위

## 공통 규칙

**지금 사람이 봐야 할 것이 맨 위.** 상단 배너가 상태를 먼저 말하고 그 아래가 상세입니다. 문제 없으면 초록, 확인할 것이 있으면 주황, 조치가 필요하면 빨강.

**빈 상태가 정상 상태.** 「확인할 것이 없어요」를 반드시 그립니다. 큐가 비어 있는 것이 실패가 아니라 목표입니다.

**숫자는 `tabular-nums`.** 세로로 자리가 맞아야 훑을 수 있습니다.

**표는 카드 안에서만 가로 스크롤.** 화면 전체가 흔들리지 않습니다.

**위험한 조작은 한 번 더.** 긴급 중지 · 변경 복구는 확인 카드를 띄우고, 무엇이 바뀌는지 항목으로 보여준 뒤 진행합니다.

**강조색은 화면당 4곳 이하.** 코랄은 활성 메뉴 · 주요 CTA · 브랜드 마크 · 강조 수치에만 씁니다.
