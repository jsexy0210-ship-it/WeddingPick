## v3.20 · 2026-09-08

### 로더 통일 · 원형 스피너 폐기

로더를 **업종 아이콘 순회** 하나로 통일했습니다.

```
결정사 → 웨딩홀 → 스튜디오 → 드레스 → 메이크업
아이콘당 410ms · 한 바퀴 2,050ms · linear 무한
```

크기만 바꿉니다.

```
20   버튼 · 행 안        박스 radius 10
28   카드 · 시트          박스 radius 12
40   화면 전체            박스 radius 14
```

각 아이콘은 흰 박스 안에 들어갑니다 — inset 1px #EAEBEE · padding 10 · stroke 1.8 coral.

**원형 스피너를 새로 만들지 않습니다.** `tokens.json`의 `motion.spinner`를 삭제하고 `motion.loaderIconCycle`로 교체했습니다.

### 아이콘 세트 · 온보딩 12업종과 통일

로더 아이콘을 5개에서 **12개**로 늘려 온보딩 진행 상황 선택지와 1:1로 맞췄습니다.

```
결정사 · 웨딩홀
스튜디오 · 드레스 · 메이크업 · 헤어변형
본식스냅 · 부케 · 청첩장
예물 · 혼수 · 허니문
```

신규 아이콘 4개 — 헤어변형 · 부케 · 청첩장 · 혼수.

**이미 결정한 업종은 순회에서 뺍니다.** 온보딩에서 결정 완료로 고른 업종은 로더가 돌지 않습니다. 「지금 찾고 있는 것」만 보여줍니다.

전체 화면 로더 제목을 «두 분에게» → **«{닉네임}님에게»**로 바꿨습니다. 배우자 연결 여부와 무관하게 쓰이던 문구였습니다.

전체 화면 로더는 아이콘당 620ms, 작은 로더는 820ms입니다.

### 잔상 수정

아이콘이 바뀔 때 2~3개가 동시에 보이던 문제를 고쳤습니다. `wpSwap` 키프레임이 5개 기준(20% 슬롯)으로 고정돼 있어 아이콘이 10개로 늘자 페이드가 슬롯을 넘었습니다.

개수별 키프레임 8종(`wpSwap5`~`wpSwap12`)을 두고 `wpSwap${ORDER.length}`로 씁니다. 슬롯 = `100/N %`, 홀드는 슬롯의 70%까지, 페이드는 슬롯 끝에서 정확히 끊습니다.

### 700ms 임계값

```
0~700ms      아무것도 띄우지 않음
700ms 초과   화면 성격과 무관하게 로더 노출
```

빈 화면이나 멈춘 화면을 보여주지 않습니다. `tokens.json`에 `motion.loaderThreshold`로 넣었습니다.

### 날짜 선택 · 연월 셀렉트 신설 (WP-APP-023)

좌우 화살표 방식을 폐기하고 **연 · 월 셀렉트 + 일 달력**으로 확정했습니다. 웨딩은 1~2년 뒤를 고르는데 화살표로는 탭이 12~24번 필요합니다.

```

연도 펼침     4열 그리드 · 올해부터 5년 뒤

달력          요일 헤더 28 + 날짜 셀 40
              일요일 #E8735F · 토요일 #5B8DEF · 타월 #DCDEE3
선택 결과     2027.05.16(토) + D-250
CTA           56 · width 100%
```

두 번 탭으로 어느 달이든 갑니다. `SPEC.md` **13.7절** 신설.

### 시트 CTA 크기 수정

`flex:1.4`가 세로 컨테이너에서 늘어나던 문제를 잡았습니다. `width:100%` + `flex:0 0 56px`로 CTA 가이드(Primary 56px)에 맞췄습니다.

## v3.19 · 2026-09-08

### 취향을 «다음 미완료 업종» 기준으로 개편

3단계에서 완료 체크한 업종의 이미지를 5단계에서 다시 묻지 않습니다. 우선순위(웨딩홀→스튜디오→드레스→메이크업→본식스냅→예물→혼수→허니문→청첩장)에서 첫 미완료 업종 하나만 취향을 받습니다. 업종별 취향 세트 9종을 정의했습니다. 11개 업종을 모두 완료했다면 이 Step을 건너뜁니다.

### 예산 질문을 «앞으로 쓸 예산»으로 통일

전체 예산이 아니라 지금부터 준비에 쓸 예산 하나만 받습니다. 준비 현황에 따라 질문이나 구간을 분기하지 않습니다 — 시작 전이면 전체 예산과 같고, 이미 일부 진행했다면 자연히 남은 예산이 됩니다.

```
질문   예산은 어느 정도 생각하세요? → 앞으로 준비에 쓸 예산은 어느 정도인가요?
구간   2,000만원 이하 / 2,000~3,000 / 3,000~4,000 / 4,000만원 이상
     → 500만원 이하 / 500~1,000 / 1,000~2,000 / 2,000~3,000 / 3,000만원 이상
라벨   예산 → 준비 예산
```

구간을 500만원 단위로 세분화했습니다. 이미 준비를 마친 사용자의 남은 예산은 전체 예산 구간보다 훨씬 작을 수 있기 때문입니다.

### 예산 매칭 기준 명시

고른 예산 구간의 최소~최대 범위와 업체 제보 금액이 **겹치는** 업체를 추천 대상으로 삼습니다. 완전 포함이 아니라 겹침 기준입니다. 「아직 모르겠어요」는 범위 제한 없이 전체를 보여줍니다.

### 초기 설정 문구 전면 정리

원칙 — **질문 → 왜 필요한지 한 줄 → 선택.** 설명이 입력 안내가 아니라 서비스가 해주는 일을 말하게 바꿨습니다.

| | 이전 | 변경 |
|---|---|---|
| 지역 제목 | 어디에서 하시나요? | 어디에서 예식하시나요? |
| 지역 설명 | 지역에 맞는 웨딩 정보를 보여드려요 | 선택한 지역에 맞춰 추천해드려요 |
| 준비 제목 | 어디까지 진행하셨어요? | 준비는 어디까지 하셨어요? |
| 준비 설명 | 없음 | 이미 준비한 건 추천에서 빼드릴게요 |
| 예산 설명 | 나중에 바꿀 수 있어요 | 예산에 맞는 선택지를 먼저 보여드릴게요 |
| 취향 설명 | 2장 이상 고르면 더 정확해져요 | 2장 이상 고르면 취향을 더 잘 맞출 수 있어요 |
| 취향 CTA | 3장 고르고 시작하기 | 3장 선택 |
| 완료 제목 | 이제 지수님에게 필요한 것만 보여드릴게요 | 이제 필요한 것만 보여드릴게요 |
| D-day | 앞으로 250일 남았어요 | 예식일까지 250일 남았어요 |
| 미정 | 아직 고민 중이에요 | 아직 정하지 않았어요 (예식일과 통일) |
| 라벨 | 진행 상황 | 준비 현황 |

### 초기 설정 · 5개 질문으로 재정렬

```
기존   [예식일 · 지역 · 예산] 1/2 → 취향 2/2
변경   예식일 1/5 → 지역 2/5 → 진행 상황 3/5 → 예산 4/5 → 취향 5/5
```

**준비 현황 Step 신설** — 이미 정한 업종을 고릅니다. 결정사 · 웨딩홀 · 스튜디오 · 드레스 · 메이크업 · 본식스냅 · 부케 · 예물 · 혼수 · 허니문 · 청첩장 10개 + «아직 시작 전이에요». 2열 카드 44px, 다중 선택. 결정한 업종은 홈 준비현황에 «결정 완료»로 들어가고 추천에서 건너뜁니다.

**은행앱 방식** — 답한 질문은 아래로 가라앉아 «라벨 · 값» 한 줄이 되고, 새 질문이 위에서 내려옵니다(wpDrop 380ms). 시선이 위쪽에 고정됩니다.

**Back 버튼 전면 제거** — 첫 질문은 다음만, 두 번째부터 이전 · 다음 두 CTA.

**미정 허용** — 예식일 «아직 정하지 않았어요» · 지역 «아직 고민 중이에요» 추가. 예산 «아직 모르겠어요» 유지. 취향만 최소 1장 필수.

**완료 CTA** — «홈으로 가기» → **«웨딩픽 시작하기»**. 제목은 «이제 지수님에게 필요한 것만 보여드릴게요».

**진행 표시** — 내부 1/2 표기를 버리고 전체 5단계 기준 «N/5»로 통일.

## v3.14 · 2026-09-08

### 초기 설정 4단계 → 2단계

예식일 · 지역 · 예산을 **한 화면**에서 이어서 묻습니다. 목록에서 하나 고르는 같은 성격이라 화면을 나눌 이유가 없었습니다.

```
기존   예식일 → 지역 → 예산 → 취향     4화면 · 1/4~4/4
변경   [예식일 · 지역 · 예산] → 취향    2화면 · 1/2~2/2
```

**고르면 다음 질문이 열립니다.** 값을 고른 질문은 위로 접혀 `✓ 예식일 · 2027년 5월 16일` 한 줄이 되고, 다음 질문이 아래에서 올라옵니다. 진행바는 8% → 38% → 68% → 100%로 이어집니다.

**되돌아가기는 접힌 줄의 「바꾸기」로** 합니다. 뒤로가기로 화면을 되감지 않습니다. 안드로이드 뒤로가기는 로그인으로 나가는 데만 씁니다.

**취향 이미지는 별도 화면 유지.** 사진을 훑는 성격이라 목록과 섞으면 둘 다 흐려집니다. 2×3 격자로 6장을 보여줍니다.

**건너뛰기 삭제.** 취향은 추천의 근거라 건너뛰면 첫 화면에 보여줄 것이 없습니다. 최소 1장을 받고 CTA에 고른 개수를 적습니다. 예산만 「아직 모르겠어요」를 남깁니다.

**다음 버튼은 값이 없으면 회색 비활성**입니다. 중간 질문에서는 고르는 순간 다음 질문이 열리므로 누를 일이 거의 없습니다.

| | 기존 | 변경 |
|---|---|---|
| 화면 수 | 4 | 2 |
| 진행 표시 | 1/4 ~ 4/4 | 1/2 ~ 2/2 |
| 되돌아가기 | 뒤로가기 | 접힌 줄의 바꾸기 |
| 취향 건너뛰기 | 있음 | 없음 |
| 취향 이미지 | 4장 | 6장 |

날짜를 고르면 필드 아래에 오늘 기준 D-day가 바로 나옵니다 — 「앞으로 250일 남았어요」 — 숫자만 코랄로 강조합니다.

예산 구간의 집계 문구(「가장 많은 구간이에요」)를 없앴습니다. 온보딩에서 남들 금액을 보여주면 앵커링이 생기고, 백엔드 집계가 필요한데 근거도 애매합니다.

예식일의 보조 칩(미정 · 봄 · 가을)을 없앴습니다. 기준이 애매해 D-day와 준비 순서를 계산할 수 없습니다. 날짜만 받습니다.

취향 이미지 3장을 실제 사진으로 교체했습니다 — 깔끔한 화이트 · 모던 미니멀 · 따뜻한 필름.

**기존 4단계 시안은 보존**합니다. `웨딩픽 진입 온보딩.dc.html`의 WP-APP-008~012는 그대로 두고 보류로 표시했습니다.
