## v3.12 · 2026-09-06

### 로그인 방식 개편 · 이메일 도입

소셜 4종에서 **카카오 + 이메일 2종**으로 줄였습니다.

**폐기** — 네이버 · 구글 · 애플 · WP-AUTH-002 다른 방법 시트

**신설 8화면** (기존 4개 → 8개로 재구성)

```
WP-AUTH-001  로그인 — 카카오 Primary + 이메일로 시작하기
WP-AUTH-002  이메일 입력 — 계정 존재 여부 판정
WP-AUTH-003  비밀번호 입력 — 기존 계정
WP-AUTH-004  비밀번호 만들기 — 신규 · 조건 3개
WP-AUTH-005  입력 오류 — 남은 시도 횟수 노출
WP-AUTH-006  비밀번호 찾기 — 이메일만 받음
WP-AUTH-007  메일 보냈어요 — 3단계 안내
WP-AUTH-008  로그인 유지 — 마지막 계정 기억
```

**설계 원칙 4개**

| | |
|---|---|
| 가입과 로그인을 고르지 않음 | 이메일로 서버가 판정해 다음 화면 결정 |
| 한 화면에 한 가지만 | 이메일과 비밀번호를 같은 화면에서 안 받음 |
| 확인 입력 없음 | 눈 아이콘으로 직접 보게 함 |
| 계정 존재 노출 금지 | 찾기는 등록 여부와 무관하게 같은 화면 |

새 비밀번호는 앱에서 받지 않습니다. 메일 링크로 웹에서 재설정하고 링크는 30분 유효합니다.

### 로그인 화면 레이아웃 규칙 추가

실 구현에서 콘텐츠가 위로 뭉치고 하단이 비는 문제가 났습니다. 원인은 브랜드 영역에 `flex:1`이 없었던 것입니다. `SPEC.md` **13.5절**에 구조 다이어그램과 실수 5행 표를 넣었습니다.

Pick Mark에 **배경 박스를 그리지 않습니다.** 하트 + 내부 체크 path 2개만입니다.

## v3.11 · 2026-09-06

### 로그인 정책 전환

**비회원 이용을 없앴습니다.** 스플래시 다음이 바로 로그인입니다.

**신설 4화면**

```
WP-AUTH-001  로그인 — 카카오 Primary + 다른 방법으로 시작하기
WP-AUTH-002  다른 방법으로 시작 시트 — 네이버 → 구글 → 애플
WP-AUTH-003  로그인 유지 — 마지막 계정 기억
WP-AUTH-004  로그인 실패 시트
```

**폐기 3화면**

| ID | 이유 |
|---|---|
| WP-APP-003 | 최초 실행 소개 · 보류 (사용자 지시) |
| WP-APP-004 | 시작 · 둘러보기 경로 없어짐 |
| WP-HOME-008 | 비회원 홈 · 정책 폐기 |

**교체**

- `WP-SHT-001` 지연 로그인 → **다른 방법으로 시작** 시트
- `WP-ST-001` 비회원 → **세션 만료**
- 회원 상태 3단계 → 2단계 (`회원` · `Pick 인증 회원`)

**이메일 로그인 미지원** — 비밀번호 입력 · 찾기 · 재설정 화면을 만들지 않습니다. 소셜 4종만입니다.

### 기기별 대응 문서 신설

`웨딩픽 디바이스 대응.dc.html`

- 기기 4종 하단 여백 실측값
- 계산식 3개 — 탭바 · dock · 시트
- 뒤로가기 처리 8행
- 플랫폼 차이 9항목
- 자간 토큰 4단계

**Android 3버튼이 하단 잘림의 원인**입니다. 시스템 바가 앱 영역 밖에 있어 inset이 0으로 옵니다.

### 사용자 흐름 보드 신설

`웨딩픽 사용자 흐름.dc.html` — 24단계 도식. 앱 진입부터 관리자까지 순서대로 나열하고 각 단계에서 원본 파일로 이동합니다.

### 핸드오프 갱신

| 플랜 | 월 정액 | 슬롯 |


기존 업체 반론을 B2B 통합 창구로 확장했습니다. `WP-BIZ-001~008` 8화면.

앱은 MY 하단, 웹은 Footer로 진입합니다. 소속 확인(사업자등록번호 대조 또는 도메인 메일)을 통과해야 반론을 등록할 수 있습니다.

**원칙** — 탈퇴 = 개인정보 삭제. 검증된 비식별 정보까지 삭제하는 것은 아닙니다.

**통합 보존기간(30일 등)을 두지 않습니다.** 항목별로 나눕니다.

```
즉시 삭제       계정 · 프로필 · 배우자 연결 · Pick · 취향 · 일정 · 지출
분리 후 유지    Pick 인증 자료 · 비식별 정보 · 작성 후기 · 금액 구간
별도 보관       신고 분쟁 기록 · 법령상 보존 항목

```
