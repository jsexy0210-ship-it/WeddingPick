WeddingPick Design System 컴포넌트 시트 모든 화면은 이 문서의 토큰과 규격만 사용합니다. 여기에 없는 값을 새로 만들지 않습니다. 기반은 SEED(당근)입니다. 색 · 타이포 · 라운드 · 굵기는 SEED 토큰을 그대로 따르고, Primary만 웨딩픽 코랄로 치환합니다. SEED는 웹폰트를 배포하지 않으므로 서체는 시스템 서체를 씁니다.
