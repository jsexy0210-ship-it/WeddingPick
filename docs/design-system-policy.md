# 웨딩픽 디자인시스템·아이콘 공통 정책

이 문서는 웨딩픽의 모든 AI와 개발자가 화면을 구현할 때 적용하는 공통 기준이다. 디자인의 유일한 정본은 `docs/design/`이며, 아래 `spec/` 파일은 구현이 읽는 런타임 구성 계층일 뿐 디자인 결정을 대체하지 않는다.

## 기준 우선순위

1. `docs/design/figma-export/` — 화면의 모양·배치·시각 시안
2. `docs/design/handoff/` — 수치·토큰·문구·상태·상호작용 규칙
3. 이 문서 — 구현·아이콘·시각 검수 절차

값이 필요하지만 원본에 없으면 임의로 만들지 말고 토큰을 먼저 추가한 뒤 전 플랫폼에 반영한다.

## 아이콘 규칙

- 이모지, 플랫폼 기본 아이콘, 임의 SVG를 사용자 화면에 사용하지 않는다.
- 하단 탭은 24px, line 1.8, round cap/join, 활성 `text.ink`, 비활성 `text.tertiary`를 쓴다.
- Pick은 `spec/tokens.json`의 하트·체크 path를 그대로 사용한다. path, viewBox, stroke width를 변형하지 않는다.
- 홈 업종 아이콘과 탭 아이콘은 `ProductSymbol` 같은 공통 컴포넌트로만 렌더링한다.
- 아이콘만 바꾸고 라벨·터치 영역·간격을 따로 바꾸지 않는다. 한 컴포넌트의 시각 비율을 함께 검수한다.

## 픽셀 검수

- 기준 뷰포트는 모바일 390px 폭이다.
- 상태별(비회원 홈, 회원 홈, 검색, 업체 상세, Pick) 스크린샷을 기준 목업과 나란히 비교한다.
- CTA는 라벨 중앙 정렬, 탭바는 아이콘과 라벨 수직 정렬을 확인한다.
- Android navigation bar와 iOS safe area를 포함해 하단 콘텐츠가 잘리지 않는지 확인한다.
- 운영 서버가 응답하지 않으면 캡처를 성공으로 표시하지 말고 장애 원인을 기록한다.

## 변경 절차

1. 현재 구현과 `docs/design/` 정본을 먼저 확인한다.
2. 공통 컴포넌트에서 수정한다. 화면별 복사 구현은 금지한다.
3. `node lint-copy.js apps/mobile apps/web`와 타입체크를 실행한다.
4. 기준 스크린샷을 갱신하고 PR 설명에 변경 화면과 검수 결과를 적는다.
