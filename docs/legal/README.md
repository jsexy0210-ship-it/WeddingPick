# 웨딩픽 외부 배포용 약관

이 폴더에는 이용자에게 제공하는 Word 형식의 약관·방침을 보관한다.

- `웨딩픽_서비스_이용약관.docx`
- `웨딩픽_개인정보_처리방침.docx`
- `웨딩픽_마케팅_정보_수신_동의서.docx`

정책의 기준 문서는 `docs/통합정책 v3.15`다 — 법적 고지 범위에 한한다. 화면·용어·값은 저장소 뿌리의
`CLAUDE.md`와 `docs/design-handoff/current/CHANGELOG.md` 맨 위(현 기준 v3.27)가 이긴다. 외부 문서에 넣기 전에 실제 사업자 정보, 수탁자, 국외 이전, 보유기간, 고객센터, 공고일·시행일 등 운영값을 확정해야 하며, 미확정 항목은 `docs/통합정책 v3.14 충돌·리스크.md`에서 관리한다.

외부 문서를 변경할 때에는 통합정책, 앱·웹 동의 화면, 실제 개인정보 처리 설정을 같은 배포 단위로 대조한다.
