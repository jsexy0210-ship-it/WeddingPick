# 웹 약관·개인정보처리방침 검토 — 2026-09-10

이 변경은 반응형 수정과 확인 가능한 문구 교정이다. 아래 운영값이 확정되지 않아 출시용 법적 검토 완료 또는 운영 배포 완료로 볼 수 없다. 시행일은 API와 같은 환경변수에 연결했다. 기존 시행일을 새 개정일로 소급 사용해서는 안 된다.

## 수정한 내용

- 개인정보 표의 고정 폭 flex 열을 의미 있는 HTML 표로 교체했다. 1023px 이하에서는 목적·항목·기간을 세로로 읽고, 목차는 키보드로 열 수 있다. 페이지의 가로 숨김으로 잘림을 감추지 않는다.
- 이용약관: 개정 거부·해지, 별도 동의, 콘텐츠 저작권·외부 광고 사용, 탈퇴 접수와 삭제 완료, 배우자 공동 기록, 계정 연결 해제와 익명화의 차이를 구분했다.
- 개인정보처리방침: 연령대의 판정 목적 및 비저장, 실제 프로필 저장 항목, 소셜 정보 제공과 위탁의 구분, 외부 분석 사본의 별도 보유기준, 기능별 이전 거부 효과, 구제기관 연락처를 보완했다.

## 배포 전에 확정할 항목

1. **시행일·개정 공지·이전 버전**: 운영 약관에는 2026-09-01이 표시되지만 개인정보처리방침에는 시행일이 없다. 새 개정일과 공지 절차를 정하고 이전 본문을 보존해야 한다. 날짜를 임의로 추가하지 않았다. 웹 빌드는 두 LEGAL_*_EFFECTIVE_ON 값을 읽고, 운영에서 누락·유효하지 않은 날짜를 거부한다. infra/render-env.yml에 두 키를 추가했다. API 대시보드에만 있고 GitHub Secrets에는 없는 값은 자동으로 복사되지 않으므로 웹 환경에도 설정해야 한다.
2. **항목별 보유기간**: 문의·신고·보안 로그·구조화 제보·파기 감사기록의 구체적 기간/종료조건 및 삭제 작업이 필요하다. 일반적인 법정 보존기간을 서비스에 일괄 적용하지 않는다. 현재 모호한 기간 문구는 아직 해결되지 않았다.
3. **국외이전**: Render·Neon 실제 리전, 계약 상대방, 백업·재위탁 국가 및 기간을 확인해야 한다. 현재 표의 미국 표기는 검증 완료된 값이 아니다. Neon에 제1항 모든 항목이 저장된다는 기존 표현도 실 DB 흐름과 대조해야 한다.
4. **이전 근거와 동의**: 업체별로 개인정보 보호법 제28조의8의 별도 동의 또는 계약 이행에 필요한 위탁·보관 등 실제 근거를 정해야 한다. 계약상 필요성·고지 완비 여부를 확인하지 않고 특정 근거를 확정하지 않았다. Expo의 정확한 개인정보 연락처·보존조건도 확인이 남았다.
5. **Anthropic 계약**: 일반 API 정책(원칙적 30일, 예외 있음)을 반영했다. 계정별 무보관 약정 여부는 확인되지 않았다. 앱 업로드 동의문(`packages/domain/src/document.ts`)과 웹의 고지사항·버전을 함께 맞춰야 한다.
6. **원본 삭제와 익명화**: 운영 저장소에서 계산된 만료시각 이후 실제 삭제 및 재시도 검증이 필요하다. 업로드부터 24시간을 보장하려면 DB 파기 일정 자체를 별도 변경해야 한다. 견적서 별도 보존조건을 본문에 추가했다. 심사 중 최대 보유기간을 정하는 정책·구현과, 후기 본문·제보 내용의 식별정보 처리 기준 및 탈퇴 화면도 맞춰야 한다.
7. **문서 동기화**: 외부 배포용 DOCX, 통합정책, 앱 동의 화면은 이 변경에서 수정하지 않았다. 확정 정책으로 동시 개정이 필요하다.
