# 여기부터는 모든 세션이 똑같이 지킨다

## 무엇을 기준으로 삼는가

전담 배정·독립 반례 검수·완료 세션 흡수와 정리는 뿌리 `AGENTS.md`의 마스터 운영 규칙을 따른다.
결과와 미해결 항목은 `docs/sync/master-status.json`으로 인계하며 작업을 마치면 PR을 건다.

동시 작업 우선순위(2026-09-11 사용자 확정): 클로드 작업과 겹치면 사용자가 지정한 Codex 마스터가
수정·검수한 변경을 우선한다. 해당 마스터는 위 상태 파일의 `masterThreadId`로 식별한다.
겹치지 않는 상대 변경은 보존하고 브랜치 전체를 덮어쓰지 않는다. 충돌 해결 사유, 양쪽 PR·검토 SHA,
선택·보존한 변경, 통합 검증 결과와 미해결 항목을 PR 및 위 상태 파일에 인계한다.
우선권은 검수된 변경 간 충돌 해결 기준이다. 미검증 자동 병합을 하지 않고 최신 사용자 지시·정책과
원래 디자인 기준, 마스터의 독립 검수·관련 통합 검증을 지킨다. 사용자가 우선순위를 명시적으로
바꾸면 관련 규칙·전달문을 함께 갱신하고 같은
작업에서 PR로 main에 반영한 뒤 병합 결과를 확인한다. 세부 기준은 `AGENTS.md`를 따른다.

- 저장소 뿌리의 `CLAUDE.md`를 **먼저 읽고** 그대로 지킨다.
- **화면에 손대기 전에 매번 `docs/design-handoff/current/CHANGELOG.md` 맨 위를 읽는다.**
  기억하고 있는 버전이 아니라 그때 파일에 적힌 것이 현행이다.
- **코드·문서·이전 규칙이 최신 핸드오프 md와 충돌하면 묻지 않고 md 쪽으로 맞춘다.**
  되묻는 것은 md끼리 어긋날 때뿐이고, 그때도 CHANGELOG 상단이 이긴다.
- **통합정책과 디자인 핸드오프는 다른 계열이다.** 번호가 둘 다 v3.x라 같은 줄로 보이지만
  아니다. 화면·값·용어는 핸드오프가, 서비스 범위·운영 원칙·데이터 정책·광고·탈퇴는
  통합정책이 정한다. 번호가 크다고 이기는 것이 아니라 무엇을 정하는 문서인지로 가른다.
- `docs/design-handoff/current/`는 **읽기 전용**이다. 전달 ZIP에서 그대로 뽑은 원본이라
  고치지 않는다.

## 화면은 목업과 1:1

- `docs/design-handoff/current/html/*.dc.html`이 그리는 그대로 맞춘다.
- **토큰에 그 값이 없으면 목업 값을 토큰에 더한다.** 가까운 기존 값으로 대신하지 않는다.
  4px·2px 차이는 따로 보면 모르지만 시안과 나란히 놓으면 드러나고, 그 자리가 어긋난 채로
  「토큰을 지켰다」고 적히면 다음 사람이 고칠 근거를 잃는다.
- 더할 때는 **어느 목업의 어느 규칙에서 온 값인지**를 `$note`와 주석에 적는다.
- **SPEC 본문과 목업이 어긋나면 목업이 이긴다.**
- 값(색·크기·간격·문구)은 `spec/tokens.json` · `spec/strings.ko.json` ·
  `spec/glossary.json`에서만 가져온다. **하드코딩 금지** — 타이포그래피 게이트가 CI에서 막는다.

## 용어

- 사용자 화면 금지: `AI` · `데이터` · `탐색` · `관심업체` · `확인된 제보` · `확인된 정보` ·
  `네이버페이 포인트` · `우리 준비` · `오늘의 Pick`. 애매모호 표현(`거의` `아마` `대략`
  `가능성이 높음`)도 금지.
- 대신: `실 제보` · `제보 금액` · `Pick 인증` · `검색` · `Pick` · `Npay` · `준비 현황` ·
  `웨딩픽 추천` · `확정`/`미확정`/`확인 필요`/`측정값`/`추정값`.
- **관리자 화면은 `AI` 용어를 써도 된다.** 나머지 금지어는 관리자에도 되도록 지킨다.
- `~할 수 없어요` `~안 해도`로 끝나는 안내를 쓰지 않는다. **무엇이 되는지**를 말한다.
- **Pick Mark SVG는 절대 변경 금지**(`spec/tokens.json`의 `symbol`).

## 관리자 화면 공통 규칙 (v3.27)

- 지금 봐야 할 것이 맨 위 — 상단 배너가 상태를 먼저 말한다.
- **빈 상태가 정상 상태** — 「확인할 것이 없어요」를 반드시 그린다.
- 표는 카드 안에서만 스크롤한다. 화면 전체가 흔들리지 않는다.
- **위험한 조작은 무엇이 바뀌는지 항목으로 보여준 뒤 한 번 더 확인**한다.
- 기준 해상도 1920×1080 · 사이드바 240 + 본문 1680 · 상단바 76 · 본문 패딩 32 ·
  카드 반지름 10 · 안쪽 20 · 카드 간격 20.
- **서버에 없는 동작은 화면에서 잠그고, 사이드바 목록에도 「조회만」으로 표시한다.**
  화면 안의 `BACKEND_PENDING`과 `_layout.tsx`의 `READ_ONLY`는 짝이다 — 서버가 붙으면
  둘을 함께 지운다. 한쪽만 지우면 말이 어긋난다.
- **없는 상태를 만들지 않는다.** 서버에 그런 상태가 없으면 단추도 두지 않는다. 눌러도
  아무 일이 없는 것이 가장 나쁘다.

## 만들 때

- **화면을 기준으로 서버 계약을 맞춘다.** 서버를 먼저 정하고 화면을 고치지 않는다.
- 권한은 기존 것을 쓴다(`requireOperatorUser` · `auth`). 새 권한 체계를 만들지 않는다.
- 되돌릴 수 없는 조작은 **사유를 받고 감사 기록을 남긴다.**
- **마이그레이션 번호를 먼저 확인한다.** 여러 세션이 동시에 만들고 있어 겹치기 쉽고,
  겹치면 하나는 적용 기록만 남고 DDL이 조용히 빠진다 — 실제로 그렇게 시험 셋이 깨졌다.
  다른 세션과 겹치지 않게 번호대를 띄워 잡는다.
- 시험을 함께 쓴다. **가드가 실제로 잡는지 고침을 도로 빼고 확인**하고, 그 결과를 PR에 적는다.

## 절대 하지 않는 것

- 비밀 값 · 전화번호 · 접속 문자열 · 내부 호스트명 · 계정 id를 **로그 · 커밋 · PR 본문에
  찍지 않는다.**
- 커밋 메시지 · PR 제목/본문 · 코드 주석에 **모델 이름을 넣지 않는다.**
- **prettier를 돌리지 않는다.**
- **지정된 브랜치 밖으로 푸시하지 않는다.**
- 릴리즈 프로덕션 빌드(앱스토어)는 **대표님이 「완료」라고 말할 때만.**
- **스테이징을 나누자고 제안하지 않는다.** 지금은 `main`에 머지하면 곧바로 운영이다
  (Render 세 서비스가 전부 `branch=main` · `autoDeploy=yes`, `Deploy → Staging`은 매번
  skipped, 스테이징 DB는 따로 없다). 그것을 알고 머지하는 것이고, 나누는 시점은
  대표님이 정한다. **「스테이징에서 확인했다」고 적지 않는다 — 볼 곳이 없다.**
- 광고 실운영 전환은 **대표님 오더 대기.** 라우트를 만들어도 기본은 꺼짐이다.

## 보고할 때

- **사람에게 말하는 모든 시각은 KST로 바꿔 적는다.** GitHub Actions · Render · DB 로그는
  전부 UTC다. UTC + 9 = KST이고 한국은 서머타임을 쓰지 않는다. `21:06 KST`처럼 시간대를
  함께 적는다. **저장하는 값과 cron은 UTC 그대로 둔다** — 거기까지 바꾸면 스케줄이 아홉
  시간 밀린다.
- 「했다」와 「확인했다」를 섞지 않는다. 배포는 `render-deploy-status`로 live 커밋을 읽고
  말한다.

## 마칠 때 — 반드시 PR을 건다

브랜치에 커밋해 두고 보고만 하는 것으로 끝내지 않는다. 브랜치는 그 세션 밖에서 보이지
않는다 — 누가 이름을 알고 일부러 열어보지 않는 한, **끝난 일이 끝나지 않은 것과 똑같이
보인다.**

- **초록으로 만든 뒤에 올린다** — typecheck · lint · 카피 린트 · jest.
- **`main`을 먼저 브랜치에 머지한다.** 일을 시작하기 전에도 한 번 한다.
- 본문에 **무엇이 어떻게 달랐고 무엇으로 고쳤는지**를 적는다. 못 고친 것과 판단이 필요한
  것은 **따로** 적는다 — 「판단 필요」를 조용히 「완료」에 섞지 않는다.
- 초안(draft)으로 올려도 된다. 머지 여부는 MASTER가 정한다.

## MASTER 쪽 의무

- 세션을 만들거나 일을 배정할 때 **위 프롬프트를 통째로 넣는다.** 「작업을 마치면 PR을
  건다」를 빼면 세션은 커밋만 하고 끝낸다.
- 배정한 뒤에 **PR이 실제로 올라왔는지 확인한다.** 커밋만 쌓여 있고 PR이 없으면 그것은
  「진행 중」이 아니라 **보이지 않는 완료**다.
- 세션을 여럿 돌리면 **마이그레이션 번호대를 미리 갈라준다.**
- 대표님을 **대표님**으로 부른다.
