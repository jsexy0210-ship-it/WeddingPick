# 앱은 공식인증 업체만 · 공공데이터는 웹으로

**2026-09-15 대표 지시.** 원문:

> 어차피 앱은 업체 공식인증 완료된것만 나오게할거고 공공데이터는 웹사이트(업체 등록용)으로
> 분류할것이다. 여기서 말하는 업체 공식인증이란 — 업체 승인을 통해 수급한 이미지와 기타 정보들

## 무엇이 정해졌나

| 자리 | 무엇을 보여주나 |
| --- | --- |
| **앱** | **공식인증 완료 업체만.** 업체가 승인한 이미지와 정보로 채워진 것 |
| **웹사이트** | 공공데이터 업체. 목적은 **업체 등록 유도**다 — 「여기 내 업체가 있네」에서 시작한다 |

**이것이 별점 문제를 닫는다.** 앞서 「가로 3장 중 하나만 ★이 뜨고 나머지는 빈다」를 걱정했는데,
그 빈 카드들이 전부 공공데이터 업체였다. 앱에서 그것들이 빠지면 섞이지 않는다. 별점은
**만든 대로(A안) 간다.**

## 지금 구조가 이것을 할 수 있나 — 재서 적는다

**칸은 이미 있다.** `structured.vendors.source`가 `source_type` enum이고 그 안에
`'public_data'`와 `'vendor_official'`이 **처음부터 둘 다 있다**(`0001_init.sql:51`).
새 마이그레이션 없이 가를 수 있다.

**그런데 아무도 `vendor_official`을 쓰지 않는다.** 저장소 전체를 세어 봤다 —
`vendor_official`이 나오는 곳은 **시험 여섯 · `seed-demo`의 플래너 · CSV 가져오기
설명 주석**뿐이고, **운영 경로에서 그 값을 쓰는 코드가 한 줄도 없다.**

    apps/api/src/public-data/sync.ts:83        VALUES($1,$2,$3,'public_data',…)
    apps/api/src/public-data-import.ts:205     VALUES ($1, $2, $3, 'public_data', …)
    apps/api/src/seed-demo.ts:93               VALUES ($1, $2, $3, 'public_data')

**그래서 오늘 앱을 «공식인증만»으로 잠그면 앱이 텅 빈다.** 지금 DB의 업체는 전부
`public_data`다. 이것이 이 작업의 가장 큰 함정이다 — 필터 한 줄을 넣는 것은 5분이고,
넣는 순간 홈 · 검색 · Pick 추천이 전부 빈 화면이 된다.

**앱 쪽에 거르는 조건이 지금은 없다.** `routes/vendors.ts`의 목록 · 검색 · 상세 질의
어디에도 `v.source` 조건이 없다. 거르는 것은 **이미지**뿐이다
(`displayableImageCondition` — `status='approved'` · `copyright_basis<>'unknown'` ·
`match_confidence >= MIN`).

**「업체 승인」 테이블은 이미 있다.** `structured.vendor_claims`(0038) — 신청 · 승인 · 반려와
`approved_vendor_claims` 뷰까지 있다. **다만 승인이 `vendors.source`를 바꾸지 않는다.**
승인 기록과 업체의 출처 표시가 이어져 있지 않다.

**이미지 쪽 근거도 이미 있다.** `image_copyright_basis`에 `'vendor_provided'`(업체가 직접
제공)가 있다(0050). 대표님이 말씀하신 「업체 승인을 통해 수급한 이미지」가 이 값이다.

## 그래서 정의를 먼저 정해야 한다 — 대표님께 여쭐 것

「공식인증 완료」를 데이터로 무엇이라고 할지가 아직 한 가지로 좁혀지지 않는다. 셋이 후보다.

| 안 | 정의 | 뜻 |
| --- | --- | --- |
| **가** | `vendors.source = 'vendor_official'` | 운영자가 그 업체를 공식으로 올렸다 |
| **나** | 승인된 `vendor_claims`가 있다 | 업체 관계자가 신청하고 승인됐다 |
| **다** | 승인된 claim **+** `vendor_provided` 이미지가 1장 이상 | 승인도 받고 사진도 받았다 |

대표님 말씀의 「업체 승인을 통해 **수급한 이미지와 기타 정보들**」은 **다**에 가장 가깝다 —
승인만으로는 「수급한 이미지」가 없다. 다만 **다**로 잠그면 사진을 아직 안 준 승인 업체가
앱에서 사라진다.

**묻지 않고 고르지 않는다**(CLAUDE.md — 정본이 제 안에서 어긋나면 대표님께 묻는다).

## 남은 일 — 전담 세션

1. **정의 확정**(위 가·나·다) — 대표님 답을 받고 시작한다
2. `vendors.source`를 실제로 `vendor_official`로 올리는 경로를 만든다 — 관리자 승인 화면에서
   승인할 때 같이 올린다. 올린 기록(누가 · 언제)을 남긴다
3. 앱 질의에 필터를 건다 — 목록 · 검색 · Pick 추천 · 상세. **한 곳에 함수로 두고 전부가
   그것을 부른다**(이미지 쪽 `displayableImageCondition`과 같은 꼴)
4. 웹은 지금대로 공공데이터를 보여준다 — 「내 업체 등록하기」 동선을 붙인다
5. **앱이 비는 구간을 어떻게 할지 정한다.** 공식인증 업체가 0곳인 동안 앱은 무엇을
   보여주나. 이것을 정하지 않으면 3번을 켤 수 없다

**3번은 5번이 정해지기 전에 켜지 않는다.** 필터만 먼저 넣고 배포하면 앱이 빈 화면이 된다.
