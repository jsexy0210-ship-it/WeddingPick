## 추가 — 실제 라이브 프리뷰 접속 결과 (다른 세션, 같은 날 보완)

위 검수는 「운영 프리뷰가 이 컨테이너 프록시 403으로 막혀 로컬 빌드로 대체했다」고
적었다. 다른 세션(이 부록)이 **같은 날 그 막힘을 풀고 실제 `210.109.82.212`을
열어 로그인 화면까지 확인했다.** 코드는 고치지 않았고, 검수 결과만 보탠다. 도구는
`scripts/audit/preview-probe.mjs` · `scripts/audit/preview-login-probe.mjs`(이 세션이 새로 작성,
읽기 전용).

**막힘을 어떻게 풀었나**: 이 컨테이너는 아웃바운드 HTTPS를 정책 프록시가 재종단한다.
Chromium이 그 프록시 CA를 신뢰하지 않아 `ERR_CERT_AUTHORITY_INVALID`로 막혔던 것이지,
목적지가 막힌 것이 아니었다(`curl`은 시스템 CA로 이미 통과했다). TLS 검증을 끄는 대신
`--ignore-certificate-errors-spki-list`로 **그 프록시 CA 하나의 SPKI 해시만** 예외로
등록해 열었다 — 이 세션의 다른 도구가 이미 신뢰하던 CA와 같은 것을 브라우저에도 신뢰시킨
것뿐이다. 스크립트가 `NODE_EXTRA_CA_CERTS`/`SSL_CERT_FILE`에서 해시를 동적으로 계산하므로
하드코딩된 값은 없다.

### 동적 라우트 `not found` — 같은 문제, 원인까지 확인

위 「확인 못 한 것」의 `[vendorId]` 등 직접 URL 진입 실패(6건)와 **같은 현상**이다. 저장소
전체에서 `generateStaticParams`를 찾으면 **0건**이라(`apps/mobile/src/app`), 동적 세그먼트를
쓰는 라우트 전부(`search/[vendorId]/*` · `wedding/[id]/*` · `community/feed/[id]` ·
`my/vendor-claims/[vendorId]` 등)가 구조적으로 같은 문제를 가질 가능성이 높다. 확인 방법:
같은 URL을 **탭 클릭으로 진입하면 정상**, **직접 로드(새로고침)하면 `not found`** —
정적 파일 서빙 방식과 무관하게(로컬 서버가 올바른 `.html`을 정확히 서빙해도) 재현되므로,
Expo Router 정적 export가 `generateStaticParams` 없는 동적 라우트를 콜드 스타트에서
매칭하지 못하는 것으로 보인다(추측 — 라우터 내부까지는 확인 못 함). **실사용 영향**: 업체
상세를 카카오톡·문자로 공유하거나 브라우저를 새로고침하면 흰 화면만 뜬다 — 못 쓴다.

### 라이브에서만 보이는 것 셋

1. **React 콘솔 오류 #419가 모든 페이지 로드마다 뜬다** — `/`, `/login` 등 시도한 경로
   전부에서 100% 재현. 화면 자체는 클라이언트 재렌더로 복구된다(눈에 거슬리는 수준). 정확한
   컴포넌트까지는 못 짚었다 — 확인 필요.
2. **`/health` 적용 마이그레이션 수가 기대보다 3개 많다** —
   `https://210.109.82.212/health` 응답: `applied:120, expected:117,
   unknown:["0052_mission_draw","0059_wedding_events","0060_vendor_geo"]`. 이 세 개가
   의도된 것인지, `expected` 갱신이 빠진 것인지는 마이그레이션 이력을 볼 세션이 판단해야
   한다.
3. **카카오 로그인 버튼 클릭 시 실제 OAuth 요청 구성 확인** — `kauth.kakao.com/oauth/authorize`로
   정상 리다이렉트했고 `client_id` · `redirect_uri=.../setup` · PKCE `code_challenge` ·
   `scope=openid profile_nickname age_range`가 전부 갖춰져 있었다. 완료는 이 세션의 네트워크
   정책(카카오 도메인 미허용)으로 못 봤지만 요청 자체는 정상으로 보인다. (애플 로그인 버튼
   미노출은 위 「확인했지만 문제 없음」 항목과 같은 결론 — `Platform.OS === 'ios'` 의도된
   분기, 코드로 재확인함.)
