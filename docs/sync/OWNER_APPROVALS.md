### A-01 · 온보딩을 3단계로 줄이나

**무엇을 정하나** 처음 가입할 때 묻는 질문을 지금 다섯 개(예식일 · 지역 · 준비 현황 · 예산 · 취향)에서 세 개(예식일 · 지역 · 중요한 것)로 줄이나.

**지금 이대로면** 코드는 다섯 단계 그대로고, 대표님이 직접 그린 루트 시안(`WP-APP-020`)도 「예식일 → 지역 → 준비 현황 → 예산 → 취향」 다섯 단계로 코드와 똑같이 그려져 있다. 취향(스타일)은 실제로 추천 순서를 정하는 데 쓰인다 — 취향이 겹치는 정도로 순위를 매긴다.

| 고르는 것 | 어떻게 되나 |
| --- | --- |
| 다섯 단계 유지 | 지금처럼 다섯 가지를 다 묻는다. 추천이 취향까지 반영해 골라준다 |
| 세 단계로 줄인다 | 준비 현황·예산·취향 질문이 없어진다. 취향이 빠지면 지금 추천 로직이 쓰는 「취향이 얼마나 겹치나」를 계산할 값 자체가 없어져 추천 정확도가 떨어진다 |

**권합니다** 다섯 단계 유지. 대표님이 직접 그린 시안도 다섯 단계이고, 취향은 추천의 근거로 실제 쓰이고 있어서 빼면 추천이 나빠진다.

**안 정하면** 온보딩 화면을 새로 손댈 때 어느 쪽 기준으로 만들지 몰라 그 작업이 멈춘다.

| 고르는 것 | 어떻게 되나 |
| --- | --- |
| 미니멀 → 도시적인 · 클래식 → 로맨틱한 | 넷 다 자리가 정해져서 새 무드 라벨을 쓰는 화면을 만들 수 있다. 다만 이 짝은 말의 느낌으로 고른 것이지 시안이나 코드에 적힌 근거는 아니다 |

| 고르는 것 | 어떻게 되나 |
