## 안 끝난 것 — 이어받을 사람이 볼 자리

### 1. 앱이 렌더되지 않는다 — 이것이 가장 크다

앱 웹 익스포트(`npm run export:web`)가 **모든 화면에서 「연결이 불안정해요」로 떨어진다.** API가 필요 없는 `/login` · `/setup`도 같고, 콘솔은 React #419(하이드레이션)다. `main` 머지 후 `--build`로 새로 빌드해도 같으며 **세 번 확인했다.**

**`scripts/screenshot-screens.mjs --edges`가 그 사실을 감춘다.** 이렇게 나온다.

```
✓ /login/     좌  20  우  20   1개    다시 시도
```

「좌 20 우 20」은 맞는 값처럼 읽히지만 잰 것은 **오류 화면의 「다시 시도」 버튼**이다. 노드가 `1개`이고 라벨이 `다시 시도`인 것이 증거다. **기대하던 수를 돌려주기 때문에 맞았다고 읽게 된다.**

읽는 법: **끝선 줄의 「N개」와 라벨을 먼저 본다.** 실제 화면이면 블록이 여럿이고 라벨이 그 화면의 글이다.

**이것이 안 풀리면 앞으로 어떤 화면 수정도 「찍어서 확인」을 못 한다.** PR 규칙이 요구하는 캡처가 지금 거짓을 찍는다. 별건이라 손대지 않았다 — 누군가 맡아야 한다.

### 2. `style-grid.tsx`를 맡은 세션에 전할 것

타일을 버튼으로 새로 만들 때 **`Layout.shellGutter`(24)를 써야 한다.** `Layout.gutter`(20)를 쓰면 이번과 똑같은 어긋남이 새 파일로 옮겨 간다.

**삭제 전까지 온보딩 스타일 단계만 좌우 20이고 나머지 온보딩은 24다.** 원복하면서 생긴 것이고, 그 파일이 없어지면 같이 사라진다.

### 4. 대표님 판단이 필요한 넷 — 2단계의 전제

`DESIGN_SYSTEM.md`에 `판단 필요`로 표시해 뒀다. **답을 받기 전까지 기준이 아니다.**

| 건 | 잰 값 | 걸리는 것 |
| --- | --- | --- |
| **FontSize 10px** | 피그마가 12화면에서 127번 | 우리 사다리 최소가 13이고 `typography.test.ts`가 그 아래를 막는다. 한글 본문 10px은 읽기 · 접근성에 걸린다 |

### 5. 2단계 영향도 (승인 전)

순서는 **Design Token → Primitive → Shared Component → 화면 하나씩**이다.

| 대상 | 수 |
| --- | --- |
| 버튼 좌우 여백 | 40군데 · **16가지** (피그마는 6가지, 좌우 비대칭 0) |
| 칩 좌우 여백 | 28군데 · **16가지** |
| `Pressable` 직접 사용 파일 | 80 |
| 화면 코드에 직접 적힌 hex | 111가지 — 최상위 규칙 1번 위반 |
| Radius 없는 값 | `16`×68 · `22`×41 · `18`×20 (129군데) |
| letterSpacing | 피그마가 쓰는 21가지가 우리 토큰에 **하나도 없다** |

## 이 세션이 배운 것 — 다음 사람이 같은 데 빠지지 않게

**재지 않고 일반화하면 회귀가 난다.** 거터 24→20이 그 예다. 「피그마 12 화면 전부가 20」이 세 곳에 적혀 있었고 전부 거짓이었다 — 스크롤 화면의 **안쪽 섹션**만 보고 열둘로 일반화한 것이다. 로그인 · 온보딩은 셸이 24를 직접 든다.

**최빈값은 기준이 아니다.** 대표님이 주신 방식은 「사용 빈도로 통합 후보를 정한다」였지만, 최상위 규칙 1번 아래에서는 **틀린 값이 다수결로 정본이 된다.** 기준은 피그마에서 재고, 우리 코드의 전수는 「얼마나 어긋나 있는지」를 보는 데만 쓴다.

**기준선을 세는 방법도 두 번 틀렸다.** 안쪽 노드를 전부 세면 달력 날짜 칸이, 폭 절반 이상만 세면 카드 안쪽 본문 열이 최빈값을 가져간다. 맞는 정의는 「**폭 전체인 조상 바로 아래로 처음 들여쓴 블록**」이다 — `measure-edges.mjs` 주석에 경위를 남겼다.

**토큰을 안 읽으면 비교가 거짓말을 한다.** 코드 문자열만 세면 우리 화면이 `FontSize.tab`을 쓰는 탓에 피그마 크기가 전부 「피그마에만 있다」로 나온다. 하마터면 없는 결함을 보고할 뻔했다.
