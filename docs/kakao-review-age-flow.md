# 카카오 심사 — 만 14세 확인 화면 플로우

2026-09-10 사용자 오더 「연령대로 수집해서 14세 미만 자동화 체크」.

이 문서는 **심사에 제출할 화면 흐름**과 그 흐름이 코드 어디에 있는지를 적는다.
값(문구 · 색 · 간격)의 원본은 `spec/`이고 여기서 다시 정하지 않는다.

## 무엇을 받고 무엇을 안 받나

받는 것은 **연령대(`kakao_account.age_range`) 하나**다(2026-09-10 확정).

**출생 연도를 받지 않는다.** 핸드오프 v3.25의 동의항목 표는 출생 연도를 필수 동의로
적었지만, 우리가 알아야 할 것은 「만 14세 이상인가」 하나다. 출생 연도는 연도만이라
생일이 지났는지 알 수 없어 만 나이가 한 살 범위로 흔들리는 반면, 연령대가 끊는
자리(`10~14` · `15~19`)는 그 질문과 **같은 자리**에 있다. 더 적게 받고 더 정확하다.

**심사 통과했다**(2026-09-10 사용자 확인). 연령대가 필수 동의로 열렸으므로 이제 로그인마다
값이 온다 — 아래 「연령대가 없을 때」는 비상 경로로 남지, 평소 경로가 아니다.

앱은 `age_range`를 scope로 **명시해서 요청한다**(`providers.ts`). 필수 동의면 적지 않아도
오지만, 콘솔에서 선택 동의로 내려가는 날 조용히 안 오게 되고 그러면 판정이 체크박스 하나로
떨어지는데 화면에는 아무 변화가 없어 아무도 눈치채지 못한다.

연령대는 **필수 동의로 설정할 수 있다**(카카오 심사 필요 · 2026-09-10 확인). 심사를
통과하면 값이 늘 오고, 체크박스는 예비 경로로만 남는다.

생일(`birthday`)은 월·일만이라 단독으로는 만 나이가 갈리지 않는다. 법정 생년월일
(`legal_birth_date`)은 본인확인 정보라 별도 제휴가 필요하고 우리 목적에는 과하다.
이름 · 성별 · CI는 요청하지 않는다.

**받은 값은 저장하지 않는다.** 판정 하나를 꺼내고 문자열은 그 자리에서 버린다
(`apps/api/src/routes/auth.ts` — `signIn`에 넘기기 전에 `profile`에서 지운다).
DB에 남는 것은 `age_verified` · `age_verified_at` 둘뿐이다.

## 세 겹으로 막는다

| 층 | 어디서 | 무엇을 |
| --- | --- | --- |
| 1 | 카카오 콘솔 | 앱을 「만 14세 미만 이용 불가」로 설정 — 동의 화면 전에 카카오가 막는다 |
| 2 | 웨딩픽 API | `age_range`를 다시 검사 — 화면을 거치지 않고 API만 부르는 경로를 막는다 |
| 3 | 가입 완료 API | `ageVerified`가 아니면 계정을 만들지 않고 세션도 끊는다 |

1층만 두면 카카오 설정이 풀렸을 때 그대로 뚫린다. 2층만 두면 카카오가 이미 아는 것을
우리가 다시 묻는 모양이 된다. 3층은 화면을 건너뛴 요청을 막는다.

## 화면 흐름

```
        WP-AUTH-001 로그인
        ├ 「만 14세 이상이에요」 체크박스 (기본 해제)
        └ [카카오로 시작하기]
                │
        ┌───────┴───────┐
   체크 안 함        체크함
        │               │
        ▼               ▼
  WP-AUTH-009     카카오 인증
  이용 불가 안내         │
                        ▼
              카카오가 나이로 막았나
              (access_denied + 연령 사유)
                ├ 예 → WP-AUTH-009
                └ 아니오
                        │
                        ▼
              서버가 age_range 판정
                ├ 14세 이상  → 통과 · age_verified 기록
                ├ 14세 미만  → 403 under_age → WP-AUTH-009
                └ 값 없음    → 체크박스 판정 그대로 통과
                        │
                        ▼
                  초기 설정 5단계
                        │
                        ▼
                       홈
```

### WP-AUTH-001 로그인 (`apps/mobile/src/app/login/index.tsx`)

- 「만 14세 이상이에요」 체크박스는 카카오 버튼 **위**에 둔다. 기본은 해제다.
- 체크하지 않고 카카오를 누르면 **로그인을 시작하지 않고** WP-AUTH-009으로 보낸다.
  버튼을 비활성으로 두지 않는 이유는, 눌리지 않는 버튼은 왜 안 되는지 말할 자리가
  없기 때문이다.
- 계정 전환(이미 로그인한 적 있는 기기)에는 체크박스가 없다 — 이미 확인한 계정이다.

### WP-AUTH-009 이용 불가 안내 (`apps/mobile/src/app/login/age-required.tsx`)

**거부 화면이 아니라 안내 화면이다.** CTA를 코랄로 두지 않는다.

v3.25 시안 27-login #27j —

```
제목   만 14세가 되면 웨딩픽을 이용할 수 있어요
안내   계정은 만들지 않았어요 / 연령대는 삭제했어요.
CTA    돌아가기
```

번호가 WP-AUTH-010에서 **WP-AUTH-009로 당겨졌다** — 옛 WP-AUTH-009(나이 확인)가
폐기되면서 빈 번호를 이 화면이 이어받았다. 문구는 「만 14세」가 세 번 나오던 것을
한 번으로 줄인 것이 요지다. 지운 문장을 되살리지 않는다.

이 화면에 오는 경로는 세 가지이고 모두 **계정을 만들지 않은 상태**다:
체크박스 미체크 · 카카오가 나이로 막음 · 서버가 14세 미만으로 판정.
「입력값을 즉시 지웠다」고 말할 입력값이 애초에 없다.

## 카카오가 나이로 막았을 때

카카오 앱을 「만 14세 미만 이용 불가」로 설정하면, 14세 미만은 동의 화면까지 가지
못하고 `access_denied`로 돌아온다. **사용자가 스스로 취소한 것과 같은 코드다.**
코드만 보고 취소로 처리하면 그 사람은 아무 안내도 못 받은 채 로그인 화면에 남아
같은 시도를 반복한다.

이유는 `error_description`에 실려 온다. 문구는 카카오가 정하고 바뀔 수 있으므로
낱말로 느슨하게 본다(`isUnderAgeDenial`, `apps/mobile/src/features/auth/providers.ts`).
못 알아보면 취소로 남긴다 — 나이로 막힌 사람을 취소로 보는 쪽이, 그냥 취소한 사람을
「이용할 수 없다」로 보내는 것보다 덜 나쁘다.

## 연령대가 없을 때

**체크박스 판정을 그대로 쓴다**(자기 신고).

심사 통과(2026-09-10) 전에는 이 경로가 평소 경로였다. 지금은 비상 경로다 — 카카오 응답이
느려 `/v2/user/me`가 실패했거나, 콘솔 설정이 바뀌었을 때만 여기로 온다. 그래도 남겨 둔다.
이 호출 하나가 실패했다고 로그인을 막으면 동의 항목 설정을 만지는 동안 아무도 못 들어온다.

v3.25 시안이 체크박스를 **남겨 두었다**(27-login #27a 「서버 판정 전 화면에서도
확인 문구를 보여주기 위해 만 14세 확인 버튼을 함께 둡니다」). CHANGELOG v3.24는
체크박스를 없앴다고 적었는데 그보다 뒤인 시안이 다시 두었으므로 시안을 따른다.

## 저장하는 것

| 컬럼 | 값 | 왜 |
| --- | --- | --- |
| `users.age_verified` | true | 확인이 끝났다는 사실 |
| `users.age_verified_at` | 확인 시각 | 언제 확인했는지 |
| `users.age_gate` | `'passed'` | 0046의 제약이 이 컬럼을 본다 |

**연령대 문자열 · 생년월일 · 출생연도는 남기지 않는다.** 이용약관 제4조 ·
개인정보처리방침 8항이 「가입 과정에서 만 14세 이상 여부만 확인하고, 판정 결과와
확인 시각만 보관한다」로 적혀 있고 코드가 그대로 한다.

## 콘솔에서 해야 할 설정

| 할 일 | 어디 |
| --- | --- |
| 연령대 **필수 동의** — 심사 필요 | 카카오 개발자센터 → 카카오 로그인 → 동의항목 |
| 만 14세 미만 이용 불가 설정 | 카카오 개발자센터 → 앱 설정 → 일반 |

두 번째를 켜면 1층 방어가 생긴다. 켜지 않아도 2·3층이 막지만, 그때는 14세 미만이
카카오 동의 화면까지 가고 나서 막히므로 겪는 흐름이 길어진다.
