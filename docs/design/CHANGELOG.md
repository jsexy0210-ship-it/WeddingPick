## v3.28 · 2026-09-22

### 전체 화면 개발 핸드오프

이번 세션에서 정리한 5개 대메뉴 파일 + 약관 관리자 도구를 개발 전달용으로 묶었습니다.

- 화면 번호를 각 파일 내에서 1→N 순차 정렬(중복·결번 제거), 하위 화면은 `N-1` 형식으로 부모 옆에 배치
- 빠진 화면 다수 보완(검색 5 · Pick 4 · 웨딩노트 4 · MY 13 · 홈 9) 후 중복 화면 통합/삭제(검색 지도보기 · 정보등록전, Pick 추천탭 3종, 웨딩노트 메모, 홈 준비현황전체보기 · TOP3전체보기 등)
- 후기 별점 UI 전면 삭제 → 3축 3지선다 + 실 제보 건수로 통일 (검색 업체상세 · MY 리얼후기 · 후기쓰기 3화면 문구 일치)
- 풀팝업/바텀시트 헤더 패턴 통일(좌측 X 닫기 + 중앙 타이틀 / 타이틀 + 우측 X)
- MY 프로필 "이름/배우자에게 보이는 이름" 2필드 → "닉네임" 1필드로 통일, 알림·계정 설정을 프로필 화면에 흡수(중복 화면 삭제)
- 약관·개인정보처리방침 사용자 화면을 MY의 자식 화면(16. 서비스 정보)으로 이동, 원본 파일은 관리자 편집 도구만 유지
- 홈 준비현황 카드 아이콘을 실제 의미(웨딩홀/스드메/본식/예물신혼)에 맞게 Material Symbols 리가처로 교체(SEED 벤더 세트에 없는 개념이라 예외 적용)
- 전역 레이아웃 오버랩/클리핑 정비 규칙 및 Legacy/Stale Artifact 정리 규칙을 CLAUDE.md에 등록
