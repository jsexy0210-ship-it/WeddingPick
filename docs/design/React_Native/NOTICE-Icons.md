# SVG 아이콘 출처

- SEED Design Icons V2, Daangn: https://github.com/daangn/seed-icon
  - SVG 메타데이터 버전: 0.7.3
  - 라이선스: Apache-2.0
- Material Symbols, Google: https://github.com/google/material-design-icons
  - Outlined / 24px / 기본 regular·unfilled 정적 SVG
  - 라이선스: Apache-2.0

개별 출처와 가공 내역은 reports/icon-sources.json에 있습니다.

원본 업로드에는 해당 아이콘 파일이 없었습니다. SEED 25개를 참조명에 대응시키고, Material Symbols 4개를 폰트 대신 SVG로 넣었습니다. history.svg는 같은 이름의 SEED 원본을 찾지 못해 Google history SVG를 명시적 대체로 사용했습니다. 업로드 원본과의 바이너리 일치를 주장하지 않습니다.

가공: SVG wrapper·그룹·공백 정리, currentColor 지정, 누락 viewBox 보충. path 도형은 위 출처를 따릅니다. 앱 문구·레이아웃·아이콘 크기·상태 색상은 이번 수정 대상이 아닙니다.

폰트 파일은 포함하지 않습니다.
