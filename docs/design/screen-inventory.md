# v3.28 화면 인벤토리 · Figma ↔ 정본 대조표

`docs/design/html/*.dc.html`에서 기계로 뽑았다(`scripts/build-screen-inventory.mjs`). 화면 태그
(`{{ tag }}`/`{{ tagId }}`/`{{ tagDesc }}`)와 각 파일 안 「정본과 다른 점」 표(`diff()`/`vdiff()` 호출)를
파싱했다 — 사람이 옮겨 적은 것이 아니다.

**`.dc.html`은 이 환경에서 렌더되지 않는다.** `_ds/`(SEED 번들)와 `support.js`가 v3.28 전달 ZIP에
없어서(용량 이유, `docs/design/README.md`) 브라우저로 열어도 빈 틀만 보인다. 이 문서는 그 대신
소스 안의 태그·설명·대조표 텍스트를 그대로 옮긴 것이다.

**열 순서는 파일마다 다른 것을 맞춰 실었다.** 검색 파일의 둘째 표만 소스에서
「항목 · 정본 · Figma · 판단」 순으로 뒤집혀 있어, 여기서는 다른 표와 같은 순서로 돌려놓았다.

| 표시 | 뜻 |
| --- | --- |
| (표시 없음) | 이미 v3.28 시안에 반영됨 — 구현이 이 값을 따라야 한다 |
| `[warn]` | 시안엔 반영했지만 재검토 여지가 있다고 적어 둠 |
| `[bad]` | 옛 코드/Figma가 실제로 규칙을 어기고 있던 자리 — 구현에서 특히 확인 |
| `[open]` | **정책 결정 대기.** 시안에 답이 없다 — 대표님 판단 없이 구현하지 않는다 |

**요약**: 화면 태그 40개 · 대조표 100건 · 정책 결정 대기 2건.
