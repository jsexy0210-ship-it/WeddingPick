# 웨딩픽 · 스타일 이미지 기준

온보딩과 MY 스타일 선택은 같은 네 스타일·이미지 기준을 사용한다. 스타일명·선택 개수는 [SPEC.md](SPEC.md) §13.6을 따른다.

## 규격과 내용

- 세로 5:6, 1000×1200 이상, 중앙 cover. 배포 이미지 용량은 250KB 이하를 목표로 최적화한다.
- 네 장 모두 예식 공간 컷으로 통일하고 사람·글자·로고·워터마크를 넣지 않는다.
- 좌하단 라벨 영역을 단순하게 두며 네 이미지를 함께 비교해 스타일 차이를 확인한다.

| 스타일 | 키 | 공간·소재·빛 |
| --- | --- | --- |
| 도시적인 | URBAN | 밝고 비어 있는 도심 웨딩 공간, 통유리·콘크리트·블랙 프레임, 측광 |
| 자연스러운 | NATURAL | 야외 가든, 원목·린넨·그린, 나뭇잎 사이 자연광 |
| 로맨틱한 | ROMANTIC | 채플·소규모 홀, 꽃·튤·캔들, 부드러운 역광 |
| 화려한 | GLAMOROUS | 채워진 호텔 볼룸, 대리석·골드·샹들리에, 짙은 톤과 조명 대비 |

## 제작·교체 기준

생성할 때도 위 표의 공간·소재·빛과 공통 금지 요소를 사용한다. 특정 생성 모델 버전·도구 전용 파라미터를 제품 디자인 기준으로 고정하지 않는다.

자산 보유 여부와 실제 경로는 최신 main의 이미지 매핑과 저장소에서 확인한다. 예전의 “없음·제작 대기” 보고를 현재 상태로 사용하지 않는다. 원본 HTML의 `uploads/` 경로는 파일 존재를 보장하지 않는다.

기존 유효 자산을 먼저 확인하고, 교체가 필요하면 권리·규격·대체 이미지를 검증한다. 이미지가 없거나 로드에 실패해도 카드 크기·라벨·선택 상태는 유지한다.
