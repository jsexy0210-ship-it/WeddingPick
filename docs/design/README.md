# 웨딩픽 · v3.29 전체 화면 개발 핸드오프

## 핵심 메시지

**플래너 없이, 직접 고르는 웨딩 준비.**
웨딩픽은 업체를 대신 골라주지 않습니다. 사용자가 직접 고르고, 웨딩픽은 실 제보 금액과 조건을 보여줍니다. `웨딩픽이 골랐어요` · `웨딩픽이 골라드려요` · `웨딩픽 TOP3` · 추천 · 결정사 · 플래너 대행 개념은 어디에도 쓰지 않습니다.

## 관리 · 웹 · 문서

`웨딩픽 관리자` · `웨딩픽 관리자 운영` (관리자, 내부 화면이라 AI · 데이터 용어 유지) · `웨딩픽 랜딩 v4` · `웨딩픽 랜딩 하위페이지` (웹, 가명 업체) · `웨딩픽 약관 방침` (약관 관리자 편집 도구) · `웨딩픽 스토어 이미지` · `웨딩픽 디바이스 대응` · `웨딩픽 컴포넌트 시트` · `웨딩픽 전체 IA` · `웨딩픽 사용자 흐름`

각 파일 안에서 화면은 번호 순서로 가로 행에 놓이고, 하위 화면(`N-1`, `N-2`)은 부모 아래 세로로 붙습니다. 카드 상단 `WP-XXX-000`이 화면 ID입니다.

## 진입 흐름

스플래시 → 카카오 로그인(버튼만) → 만 14세 미만이면 이용 불가 → 약관 동의(필수 5 · 선택 3 · 앱 접근 권한 안내) → 초기 설정 5단계 → 홈.

- 약관 필수: 만 14세 이상 · 서비스 이용약관 · 개인정보 수집 · 이용 · Pick 인증 자료 수집 · 이용 · 상담 녹음 수집 · 이용
- 약관 선택: 상담 예약 시 업체에 연락처 제공 · 혜택 · 이벤트 알림 · 야간 알림
- OS 권한(알림 · 카메라 · 사진 · 마이크)은 안내만 하고, 각 기능을 처음 쓸 때 하나씩 요청합니다.
- 약관 상세는 공통 풀팝업(탭 6개)이고 조문은 법무 확정 전 임시 문구입니다.

## 디자인시스템

- 기준 **SEED Design System (Karrot)**.
- 예외: 홈 «내 웨딩 준비» 4칸 아이콘만 Material Symbols Outlined(`storefront` · `face_retouching_natural` · `dry_cleaning` · `diamond`, 20px). 구현 시 교체 가능.
- Pick Mark(하트 + 체크)는 절대 변경 금지. PROJECT_RULES.md의 확정 path를 그대로 씁니다.

## 공통 헤더 규격

- 56px · 좌우 16px · 하단 1px 구분선 · 타이틀 16px bold 중앙.
- 좌측 36px 슬롯: 풀팝업은 회색 원형 X(16px 아이콘), 일반 화면은 뒤로가기(24px 아이콘, 36px 터치영역). 우측 36px 빈칸으로 타이틀 중앙 정렬.
- 바텀시트: 타이틀 + 우측 X.

## 용어 규칙

- 사용자 화면에 `AI` · `데이터` 금지 → `웨딩픽 콘텐츠` · `실 제보` · `실 제보 N건` · `아직 정보가 적어요`.
- 정보 체계 3단: `실 제보` → `제보 금액` → `Pick 인증`.
- 애매 표현 금지(`거의` `아마` `대략`) → `확정` `미확정` `검증 전` `확인 필요`.
- `탐색` → `검색`, `관심업체` → `Pick`.
- 후기는 별점 없이 3축 3지선다(상담 · 결과물 · 금액 안내, 모두 긍정 톤) + 실 제보 건수.

## 레이아웃 규칙

Header / Tab / Filter / Content / Bottom은 겹치지 않습니다. 고정 height 금지(`auto`/`min-height`), 가로 탭 · 칩은 한 줄 + 가로 스크롤, 세로 콘텐츠는 탭바 · Safe Area만큼 bottom padding. 화면별 패치 대신 공통 컴포넌트에서 고칩니다.

## 예시 데이터

웹은 가명 업체(`강남 A 스튜디오`)와 샘플 이미지, 앱은 실제 업체명 · 실제 이미지. 금액은 실 제보 집계 구간.

## 미확정

- 광고 실운영 전환: 사용자 오더 대기
- 실제 이미지: 대기 중(규격은 컴포넌트 시트)
- 약관 조문 · 삭제 기한(Pick 인증 원본 30일 · 녹음 원본 7일 · 업체 연락처 보관 6개월): 법무 검토 필요
- `웨딩픽 사용자 흐름`은 옛 파일 링크가 남아 있어 현재 대메뉴 파일 기준으로 재작성 필요

## About the Design Files

이 HTML 파일들은 디자인 레퍼런스입니다. 화면 구성 · 문구 · 상태 분기를 보여주는 프로토타입이며 그대로 쓰는 프로덕션 코드가 아닙니다. 타겟 코드베이스의 기존 패턴과 컴포넌트로 다시 구현하세요. `x-dc` · `sc-for` · `sc-if`는 디자인 툴 전용 문법이니 무시하고 렌더링 결과와 문구만 참고합니다.

## Fidelity

High-fidelity. 색상 · 타이포 · 여백 · 컴포넌트 구조가 SEED 값 그대로이고, 카피는 확정 문구입니다.
