# 디자인 정본 — docs/design만 사용

이 저장소의 디자인 Source of Truth는 `docs/design/` 하나다.

```
docs/design/figma-export/   화면의 모양 · 배치 · 시각 시안
docs/design/handoff/        수치 · 토큰 · 문구 · 정책 · 화면 규칙
```

## 적용 순서

1. 화면의 모양과 배치는 `figma-export/`를 따른다.
2. 수치·토큰·문구·정책·상태 규칙은 `handoff/`를 따른다.
3. 둘이 어긋나면 모양은 `figma-export/`, 값과 규칙은 `handoff/`를 각각 적용한다.
4. 그래도 충돌하면 임의로 고르지 않고 사용자에게 확인한다.

## 정본 시안

`figma-export/`의 화면군은 홈, 검색, Pick, 웨딩노트, 업체 상세, 온보딩·로그인, 라운지·MY, 추천, 다이얼로그다.

## 공통 원칙

- 디자인 작업은 `docs/design/` 밖의 별도 디자인 폴더를 만들지 않는다.
- 디자인 자료를 복제해 별도 세대·백업·정본 폴더를 만들지 않는다.
- 화면 검수는 정본과 실제 구현을 같은 상태로 캡처해 나란히 대조한다.
- 파일 존재, 타입 검사 통과, 화면 ID 주석만으로 디자인 완료 처리하지 않는다.
