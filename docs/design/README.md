## 디자인시스템

- 기준: **SEED Design System (Karrot)**. 색상 · 타이포 · 컴포넌트 스펙은 SEED를 따릅니다.
- 예외 1건: 홈 화면 준비현황 카드 4개(웨딩홀 · 스드메 · 본식 · 예물·신혼) 아이콘만 SEED 벤더 세트에 없는 개념이라 **Material 3의 Material Symbols Outlined 리가처 폰트**(`storefront`, `face_retouching_natural`, `dry_cleaning`, `diamond`)를 예외적으로 사용합니다. 개발 시 실제 아이콘 세트로 자유롭게 교체 가능합니다.
- Pick Mark(하트+체크 심볼)는 **절대 변경 금지** — 프로젝트 CLAUDE.md에 확정 path 값이 있습니다.

## 용어 규칙 (필수 준수)

- 사용자 화면에 `AI` · `데이터` 단어 금지. `웨딩픽이 골랐어요` · `실 제보` · `실 제보 N건` 사용.
- 정보 체계 3단: 상위 개념 `실 제보` · 금액 `제보 금액` · 제공 행동 `Pick 인증`.
- 애매 표현(`거의` `아마` `대략`) 금지 → `확정` `미확정` `검증 전` 등 사용.
- `탐색`→`검색`, `관심업체`→`Pick`.
- 후기는 **별점 대신 3축 3지선다**(상담/진행/금액 등) + 실 제보 건수. Figma 원본의 별점 UI는 정본에서 전부 제거된 상태입니다.

## 예시 데이터

- 웹은 가명 업체(`강남 A 스튜디오` 형식)와 샘플 이미지 유지.
- 앱 실제 구현 시 가명 → 실제 업체명 · 실제 이미지로 교체.
- 금액은 실 제보로 집계한 실제 구간 사용.

## 공통 레이아웃 규칙 (CLAUDE.md 반영)

- Header / Tab / Filter / Content / Bottom 영역은 서로 겹치지 않는다. `sticky`/`fixed`/`absolute` 사용 시 다음 콘텐츠가 그 높이만큼 공간을 확보한다.
- 콘텐츠 영역에 불필요한 고정 height 금지. `auto`/`min-height` 기반.
- 가로 탭 · 칩은 압축하지 않고 한 줄 + 가로 스크롤.
- 세로 콘텐츠는 정상 스크롤, 하단 콘텐츠는 탭바 · Safe Area에 가리지 않게 bottom padding 확보.
- 화면별 임시 패치 대신 공통 컴포넌트(헤더 · 탭바 · 칩바 · 카드) 단위로 수정.

## 공통 풀팝업 / 바텀시트 UX

- 풀팝업: 헤더 좌측 X 닫기 + 중앙 타이틀 (뒤로가기 chevron 아님). 결정한 업체 · 메모 · 변경내역 · 지출목록 · 비교 화면에 적용.
- 바텀시트: 타이틀 + 우측 X 닫기 공통 패턴 (지역선택 · 정리결과 · Pick 확인 시트 등).

## 진행 상태 / 미확정 사항

- 광고 실운영 전환: 사용자 오더 대기.
- 실제 이미지: 대기 중, 규격은 컴포넌트 시트 참조.
- 홈은 C-1 안 확정.

## About the Design Files

이 폴더의 HTML 파일은 **디자인 레퍼런스**입니다 — 의도한 화면 구성 · 문구 · 상태 분기를 보여주는 정적 프로토타입이며, 그대로 복사해 쓰는 프로덕션 코드가 아닙니다. 실제 구현 시 타겟 코드베이스(React Native / Flutter / 네이티브 등)의 기존 패턴과 컴포넌트로 다시 만드는 것이 목표입니다. HTML의 `x-dc`/`sc-for`/`sc-if` 등은 이 디자인 툴 전용 문법이므로 무시하고, 렌더링된 화면 구조와 문구만 참고하세요.

## Fidelity

**High-fidelity.** 색상 · 타이포 · 여백 · 컴포넌트 구조가 SEED 디자인시스템 값 그대로 반영돼 있습니다. 문구(카피)는 그대로 사용 가능하며 임의로 바꾸지 마세요.

## QA

`handoff-QA-체크리스트.md`에 인증/세션 · 네트워크 · 데이터정합성 · 동시성 · 캐시 · OS별(iOS/Android) · 보안 · 관리자연계 · 배포/Rollback까지 Release Readiness 수준 QA 항목이 정리돼 있습니다. 개발 완료 후 이 문서 기준으로 검수하세요.
