## 1. AI 분석 결과 표시 정책

**원칙**: AI = 읽기, Server = 계산 (사업계획서 27번 섹션)

- AI 분석 결과 화면 상단에 고정 고지: *"AI 분석 결과이며 법적 효력이 없습니다. 원본 문서를 기준으로 판단하세요."*
- 신뢰도 낮은 추출 항목은 숨기지 않고 "확인 필요" 배지로 노출
- 핵심 필드(계약금액, 계약일, 환불조건)는 예외 없이 사용자 확인 단계를 거친 뒤에만 비교·저장에 반영
- 원본 문서와 AI 분석 결과가 다를 경우 원본이 우선한다는 사실을 결과 화면에 명시

## 2. 데이터 검증 등급 운영기준

| 등급 | 조건 | 시장가격 반영 여부 |
|---|---|---|
| L0 미인증 | 사용자 입력만 존재 | 미반영 |
| L1 견적인증 | 실제 견적자료 확인 | 미반영 |
| L2 계약인증 | 실제 계약자료 확인 | **반영 시작** |
| L3 이용인증 | 실제 이용 확인 | 반영 (가중치 상향) |
| L4 최종금액 인증 | 최종 결제자료 확인 | 반영 (가중치 최상) |

- 등급은 UI에서 항상 배지로 표시, 등급별 아이콘/색상 고정
- 등급 판정은 1차 자동판정 → 이상 패턴 감지 시 수동 재검토
- 자동판정 기준(증빙자료 매칭 규칙)은 별도 내부 문서로 관리, 공개하지 않음 (판정 회피 악용 방지)

## 3. 배우자 연결 및 해제 정책

- 연결: 초대 링크 방식, 양측 동의 필요
- 연결 중: 후보·견적·분석결과·가계약·계약·비용·비교·의견·메모 공동 관리. **원본 문서·개인정보는 공유 대상에서 항상 제외**
- 해제: 이용자 단독으로 언제든 해제 가능. 해제 즉시 상대방의 데이터 접근 권한 종료
- 해제 후 데이터: 공동 생성 데이터(비교 결과, 공동 메모 등)는 해제 시점 스냅샷을 각자 보관, 이후 변경 불가
- 분쟁 상황(이혼·파혼 등) 발생 시에도 회사는 중재하지 않으며, 연결 해제 기능만 기술적으로 제공

## 4. 개인정보 처리 파이프라인 운영기준

```
문서 업로드 → AI 분석 → 개인정보 탐지/마스킹 → 구조화 → 검증 → 보관 → 원본 자동삭제
```

- 원본 보관 기간: **검증 완료 후 30일** (2026-08-28 확정). 검증 완료는 업로드·사용자 확인·인증 심사 결론 중 가장 나중이며, 심사가 열려 있는 동안에는 셈이 시작되지 않는다
- 자동삭제 실패 시 알림 및 수동 처리 프로세스 마련
  - 구현: 제품·기술 명세 15번. 파기는 사람이 하고, 때가 되면 운영자에게 푸시로 알린다
- 원본 / 마스킹된 구조화 데이터 / 통계 데이터는 물리적으로 분리 저장
- 개인정보 탐지 자동화 초기 정확도가 100%가 아니므로, 오픈 초기엔 사람 재검토 1단계 유지
  - 구현: 제품·기술 명세 16번. 검토를 받지 않은 문서는 시장 대표가격에 들어가지 않는다

## 5. 광고-평가 분리 운영정책

- Sponsored Exposure는 노출 위치·순서에만 영향, 다음 항목에는 절대 영향 없음: 가격 정보, 이용점수, 후기, 실제 계약 중앙값, 인증 정보
- 광고 콘텐츠는 UI상 "광고" 배지로 항상 구분 표시
- 광고주 업체와 평가 데이터 담당 조직/프로세스를 분리 운영 (동일 담당자가 광고 영업과 인증 판정을 겸하지 않음)

## 6. 업체 반론권 처리 절차

1. 업체가 특정 데이터(견적, 계약가, 후기 등)에 이의 제기
2. 접수 후 [영업일 기준 O일] 이내 증빙 재검토
3. 명백한 오류/허위 확인 시 데이터 수정 또는 삭제
4. 애매한 경우 원 데이터 옆에 업체 공식 반론 병기
5. 반론 처리 이력은 내부 로그로 보관 (반복 이의제기 패턴 파악용)

## 7. 리워드 운영정책

- 대상: 견적 인증(L1), 계약 인증(L2), 최종금액 인증(L4) — 등급별 차등 지급
- 자동승인 금지, 증빙 확인 후 지급
- 동일인 반복 제보, 이상 패턴(동일 IP 다건 등) 필터링 기준 적용
- 리워드 지급 시 세금 처리(기타소득 등) 관련 절차는 법률검토 문서 참조

## 8. 콘텐츠 게시 기준

- 게시 가능: 검증된 견적/계약 데이터, 이용 후기, 업체 공식 반론
- 게시 불가: 특정 개인 식별 가능 정보(상담원 실명 등), 확인되지 않은 비방성 표현, 저작권 침해 콘텐츠(업체 무단 도용 이미지 등)
- 이미지는 업체 공식 이미지 / 실제 이용자 이미지를 라벨로 구분 표시

## 9. 웹-앱 역할 분리 운영기준

- 웹: 서비스 소개, 기능 소개, 앱 다운로드 유도, 정책 문서 게시, 캠페인 랜딩만 운영
- 웹에서 앱 기능(가격비교, 업체비교, AI 분석 등)을 재현하지 않음
- 웹 최우선 KPI: App Download Conversion — 이 원칙에 반하는 웹 기능 확장은 하지 않음
