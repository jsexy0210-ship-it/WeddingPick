# 관리자 로그인 — 설계 결정

2026-09-10 사용자 결정 — **관리자는 별도 로그인 계정을 쓴다.**

## 지금 상태 (2026-09-10 실측)

관리자 로그인 화면이 **없다.** 링크를 누르면 이렇게 된다:

```
/admin  →  admin/index.tsx 가 인증 확인 없이 /admin/queue 로 리다이렉트
        →  admin/_layout.tsx 는 사이드바 + Slot 뿐, 인증 게이트 없음
        →  admin/_api.ts 가 일반 사용자 세션 토큰을 그대로 붙임
        →  서버(requireOperatorUser)가 403
        →  화면은 떴는데 전부 오류. 「로그인하세요」라고 말하는 자리가 없다
```

핸드오프 `screens.json`에 관리자 화면 26개(`WP-ADM-001~`)가 정의돼 있는데 **로그인 화면은
그 목록에 없다.** 그런데 `tokens.json`과 `PROJECT_RULES.md`는 Pick Mark 적용처로
「관리자 로그인/사이드바」를 적어 두었다 — 화면은 전제돼 있는데 정의가 없다.

## 결정

**아이디 · 비밀번호로 로그인하는 관리자 전용 경로를 만든다.**

v3.25가 이메일 로그인을 폐기하고 「카카오 단일 로그인」으로 확정했지만, 그것은
**사용자 화면의 결정이다.** 관리자는 그 결정의 예외로 둔다 — 운영자는 앱 사용자와
같은 사람일 필요가 없고, 카카오 계정에 운영 권한을 매다는 것보다 분리하는 편이
권한을 회수하기 쉽다.

## 지켜야 할 것

### 비밀번호 원문은 저장소에 없다

**어떤 경우에도 원문을 커밋 · 문서 · 로그 · PR 본문에 적지 않는다.** 서버가 아는 것은
scrypt 해시뿐이다(`identity.email_credentials`가 이미 `scrypt$<salt>$<key>` 꼴을 쓴다 —
0076 참고).

아이디와 해시는 환경변수로 온다. 저장소에는 **이름만** 적는다:

```
ADMIN_LOGIN_ID
ADMIN_PASSWORD_HASH
```

`infra/render-env.yml`의 `secrets` 목록에 이름을 더하면 GitHub Secrets의 같은 이름에서
Render로 흘러간다. 값을 이 파일에 적지 않는다.

### 해시는 사람이 만든다

원문을 인자로 받지 않는 작은 도구를 둔다 — 인자로 받으면 셸 기록에 남는다.

```
npm run admin:password-hash    # 표준입력으로 받아 해시만 찍는다
```

### 실패는 무엇이 틀렸는지 말하지 않는다

「아이디가 없어요」와 「비밀번호가 틀렸어요」를 가르면 아이디가 있는지 확인하는 데
쓰인다. 한 문장으로 답한다.

### 시도를 제한하고 남긴다

무차별 대입을 막는다. 실패도 성공도 감사 로그(`audit-log`)에 남긴다 — 관리자 권한이라
누가 언제 들어왔는지 나중에 물을 일이 생긴다.

### 세션은 운영자 TTL을 쓴다

`config.operatorSessionTtlDays`가 이미 있다. 일반 사용자보다 짧다.

## 만들 것

| 무엇 | 어디 |
| --- | --- |
| 로그인 화면 | `apps/mobile/src/app/admin/login.tsx` |
| 인증 게이트 | `apps/mobile/src/app/admin/_layout.tsx` — 운영자 세션이 없으면 로그인으로 |
| 로그인 API | `POST /v1/admin/sessions` |
| 해시 도구 | `apps/api/src/admin-password.ts` |
| 환경변수 이름 | `infra/render-env.yml` |

`admin/index.tsx`의 무조건 리다이렉트를 먼저 없앤다 — 인증을 확인하기 전에 내부 화면으로
보내는 줄이 지금 문제의 시작이다.

## 시안이 없다

이 화면은 핸드오프에 정의가 없다. **화면을 지어내기 전에 사용자에게 확인한다** —
관리자 화면은 시안 26개가 이미 있으므로, 로그인 화면만 임의로 만들면 나중에 시안이
왔을 때 두 번 만들게 된다. 급하면 사이드바와 같은 톤(`#17181c`)에 Pick Mark를 얹은
최소 화면으로 시작하고, 그 사실을 화면 주석에 적어 둔다.
