# scripts

## 공정률 브리핑 — `npm run progress`

매일 오전 9시(KST)에 나가는 공정률 보고의 계산기다. 사람이 손으로 적는 숫자가 아니라
저장소에 이미 있는 것을 세기만 한다. 문서를 고치면 다음 날 브리핑이 따라 움직인다.

```bash
npm run progress                          # 오늘 브리핑 (어제와 비교)
npm run progress -- --checks              # 타입체크·린트·테스트까지 돌려서 코드 게이트도 측정
npm run progress -- --format markdown     # 붙여넣기용
npm run progress -- --format json         # 기계용
npm run progress -- --compare "7 days ago"
```

### 무엇을 세는가

| 공정 | 세는 것 | 근거 |
|---|---|---|
| 화면 구현 (30) | `A-NN ✅` 표시된 화면 수 | `docs/05-product-spec.md` 2번 표 |
| 열린 질문 해소 (20) | `- [x]` 체크된 질문 수 | `docs/05-product-spec.md` 열린 질문 절 |
| 명세 항목 완결 (30) | `### 아직 없는 것` 에 남은 항목이 없는 `##` 절의 수 | `docs/05-product-spec.md` 전체 |
| 코드 게이트 (20) | `typecheck` · `lint` · `test` 통과 수 | 실제 실행 (`--checks` 일 때만) |

가중치는 `scripts/progress.config.json` 한 곳에 있다. **가중치를 바꾸면 그날의 공정률이
그만큼 움직이므로, 바꾼 이유를 커밋 메시지에 남긴다.**

### 세지 않는 것도 적는다

`화면 구현 100%` 는 **05번 명세의 화면표 18개**를 잰 값이지, 제품 전체가 다 됐다는
뜻이 아니다. 관리자 콘솔 웹 UI는 그 표에 행이 없어 세지지 않는다 — 지금 웹은 랜딩 한
장이고 운영은 CLI 10개로만 돈다. **측정 범위 밖의 일이 있으면 공정률은 실제보다 높게
나온다.** 그래서 브리핑은 `이 공정률이 재지 않는 것` 을 매번 함께 낸다
(`progress.config.json` 의 `outOfScope`).

### 재고 — 분모를 모르는 것은 비율로 내지 않는다

전체가 몇 개여야 하는지 모르는 것(관리자 화면이 몇 장이어야 하는가 같은 것)은 비율로
만들지 않는다. 대신 개수를 세어 어제와 견준다. 문서가 안 움직인 날에도 코드가
움직였는지는 이 줄에 남는다 — 모바일 라우트 · API 라우트 모듈 · 운영 CLI · 관리자
웹 UI · DB 마이그레이션 · 도메인 모듈 · UI 컴포넌트 (`progress.config.json` 의
`inventory`).

### 지키는 규칙 셋

1. **숫자를 만들어내지 않는다.** 모든 비율에 분모(모수)와 근거 파일을 붙여 낸다.
   `78.3%` 만 있고 `27/35 절` 이 없는 줄은 내지 않는다.
2. **재지 못한 것은 0이 아니다.** `--checks` 없이 돌리면 코드 게이트는 `미측정`이 되고
   가중치 20이 분모에서 빠진다. 0으로 세면 없는 지연을 만들고, 100으로 세면 없는
   진척을 만든다.
3. **바깥에서 와야 하는 값은 공정률에 넣지 않는다.** `결정 필요` 항목(클라이언트 ID,
   도메인, 법률 확인 같은 것)은 코드로 닫을 수 없다. 따로 세어 목록으로만 보여준다.
   공정률에 섞으면 우리가 못 움직이는 것을 우리 진도로 읽게 된다.

### 어제와 오늘을 어떻게 견주는가

같은 계산기를 `git show <커밋>:<파일>` 로 과거 커밋에 그대로 돌린다. 스냅샷 파일을
따로 쌓지 않으므로 기록이 어긋날 일이 없고, 계산 규칙을 고치면 어제 값도 같은 규칙으로
다시 계산된다. 코드 게이트만 실행 결과라서 과거에는 돌리지 않는다(그래서 `미측정`).

### 자동 실행

매일 오전 9시(KST) Routine 이 세션을 열어 이 스크립트를 돌리고 브리핑을 보낸다.
스크립트만 있으면 어디서든 같은 숫자가 나오므로, 자동 실행이 멈춰도 손으로 돌리면 된다.
