# @weddingpick/web

웹. 정적 HTML을 만든다.

```bash
npm run build --workspace @weddingpick/web   # → apps/web/dist/
```

| 나오는 것 | 무엇 |
|---|---|
| `index.html` | **WP-WEB-001 홈.** 검색과 확인된 금액 |
| `v/<업체 id>.html` | **WP-WEB-003 업체 상세** |
| `about.html` | 서비스 소개 한 장. 약관·자료 출처·분석 안내가 여기 있다 |
| `admin.html` | 관리자 |

프레임워크도 런타임 자바스크립트도 없다. 검색으로 들어온 사람에게 필요한 것은 글과 링크와
검색칸뿐이고, 자바스크립트를 켜지 않아도 읽히고 눌려야 한다. 검색칸은 GET form이다.
CSS는 한 파일에 담아 인라인으로 넣는다.

## 웹이 맡는 일

**검색 유입과 업체·플래너 창구.** Pick과 우리웨딩처럼 사람마다 달라지는 것은 앱이 맡고,
웹에서는 확인된 정보를 로그인 없이 보여준다. 그래서 이 화면에는 로그인해야 보이는 것이
없고, 웹에 로그인 칸도 두지 않는다 — 웹에서 계정을 만들 수 있다는 말이 되고, 만들어도
웹에서 볼 것이 없다.

업체 상세의 `Pick하기`·`비교하기`는 앱으로 넘긴다. 우측 카드가 그 이유를 그대로 적는다.

## 글은 어디서 오나

바뀔 수 있는 것 — 숫자, 기준, 출처, 게시 상태, 업체 이름, 안내 문구 — 은 이 워크스페이스에
적지 않는다. 랜딩에 따로 적어두면 기준이 바뀔 때 한쪽만 고쳐지고, 그때 어느 쪽이 우리가
지키는 약속인지 알 수 없게 된다.

| 화면의 내용 | 출처 |
|---|---|
| 업체·구간·건수·캡션 | API `GET /v1/vendors`, `GET /v1/vendors/{id}` |
| 몇 건부터 무엇을 보여줄지 | `disclosure.ts` — 화면은 4단계 사다리를 그대로 그린다 |
| 업체 상세의 자리와 순서 | `vendor-detail.ts` — 앱·웹·IA가 같은 목록을 본다 |
| 용어(`확인된 정보`·`Pick`·`검색`) | `terms.ts` |
| 업종 이름 | `vendor.ts` |
| 약관·정책의 게시 상태 | `policies.ts` — 앱 정책 화면도 같은 것을 쓴다 |
| 금액 표기(`152~184만원`) | `disclosure.ts`의 `rangeLabel`·`manwon` |

웹 자체의 소개 문구만 [`src/site-content.ts`](src/site-content.ts)에 있다.
소개 한 장의 문구는 그대로 [`src/content.ts`](src/content.ts)에 있다.

`src/site.test.ts`가 이 연결을 지킨다 — 금지어가 그려진 문서에 남지 않았는지, 구간이 없는
단계에서 금액을 그리지 않는지, 없는 주소를 지어내지 않는지, 옮겨 적은 색·심볼·글자 크기가
갈라지지 않았는지.

## 아직 채우지 않은 자리

업체 상세에는 정책이 정한 열세 자리가 있고 몇은 아직 우리에게 자료가 없다
(`vendor-detail.ts`의 `ready: false`). 그 자리는 **목록에서 지우지 않고 왜 비었는지
적는다** — 회색 자리를 뚫어두는 것을 정책이 막았고, 지워버리면 자료가 생기는 날 어디에
넣을지 다시 정해야 한다.

대표 이미지·이런 점이 잘 맞아요·업체 안내·받을 수 있는 혜택가 지금 그 상태다. 시안에는
사진과 추천 이유가 채워져 있지만, 자료가 없는 것을 채워 그리면 그건 시안대로 만든 것이
아니라 없는 것을 만들어 쓴 것이 된다.

## 설정

| 환경변수 | 없으면 |
|---|---|
| `WEDDINGPICK_API_URL` | 홈은 "정보를 모으는 중이에요"로 나오고 업체 상세는 만들어지지 않는다. 예시 숫자를 채운 화면을 내보내지 않는다 |
| `WEDDINGPICK_WEB_VENDOR_IDS` | 업체 상세를 만들지 않는다. 쉼표로 이어 준다 — `id1,id2` |
| `WEDDINGPICK_CONTACT_EMAIL` | 소개 한 장의 문의처를 "아직 정해지지 않았습니다"로 적는다. 지어낸 주소를 붙이면 사람들이 받지 않는 곳으로 편지를 보낸다 |

업체 상세를 어느 업체까지 미리 만들어 둘지는 빌드하는 쪽이 정한다. 웹이 업체를 고르지
않는다 — 고르기 시작하면 그것이 노출 순서가 되고, 그건 우리가 정한 순서가 된다.
