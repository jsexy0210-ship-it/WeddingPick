# @weddingpick/domain

앱과 서버가 함께 쓰는 도메인 타입과 계산 규칙. 호스팅·프레임워크에 기대지 않는다.

여기 있는 것:

- **엔티티 타입** — 문서·업체·플래너·웨딩·가격 통계 (docs/05 3번)
- **검증 등급 규칙** — L0~L4와 시장가격 반영 기준 (서비스정책서 2번)
- **가격 계산** — 중앙값·분위수·표본 부족 처리·가격 판단 (사업계획서 9번, 27번)

여기 없는 것: 저장소 접근, HTTP, UI. 순수 함수와 타입만 둔다.

사업계획서 27번의 **"AI = 읽기, Server = 계산"** 중 계산 쪽이 이 패키지다. AI가 추출한
값은 입력으로만 들어오고, 중앙값·판단·통계는 전부 여기서 만든다.

## 확정되지 않은 값

`src/policy.ts`에 모아뒀다. 최소 표본 수와 가격 판단 경계는 아직 정해지지 않아 잠정값을
쓰고 있으며, 정해지면 그 파일만 고치면 된다.
